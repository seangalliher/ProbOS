## 1. Problem

- #1604 property 1 asks for "a structural guard test that every M0 seam and every effect-point primitive (model call, tool call, subprocess, egress, store write) calls the shadow `decide()` or the shadow sink check, or holds a pinned `system` principal from a pinned allowlist". On `485bed6e`:
  - The sink checks stand at two effect points only: `tools/registry.py:398` and `cognitive/llm_client.py:1473`. SK7 pins that set (`tests/test_ad1346_admission_ticket_sinks.py:506-507`).
  - `TICKET_EFFECTS` is `(SEAM_TOOL, SEAM_MODEL_CALL)` (`tickets.py:60`). `TicketRegistry.check` raises `ValueError` for any other effect (`:265-266`).
  - `SYSTEM_PRINCIPALS` is `frozenset({"system:ship_computer"})`, with the comment "D17: grows by census in AD-1346 M3e." (`taxonomy.py:105-106`). No `src` site presents a `system:` literal (Absence Verified).
- The plan's "21 subprocess calls in 15 files" is wrong. Grep of `subprocess\.(run|Popen|call|check_call|check_output|getoutput|getstatusoutput)\(|create_subprocess_(exec|shell)\(|os\.(system|popen|spawn\w*|exec\w*)\(` over `src` finds 38 call lines in 22 files (plus two docstring lines). One more launch is a by-reference `subprocess.run` handed to `asyncio.to_thread` (`cognitive/scout.py:406`). That makes 39, which equals BF-892's `_KNOWN_LAUNCH_FLOOR = 39` ("Launches found at 7301f647 (2026-10-14)", `tests/test_bf892_spawn_env_guard.py:77-78`).
- BF-892 already holds a launch census: `_scan_tree()` (`:476-482`) yields every launch it finds under `src` as a `Launch(path, line, callee, shape, scope, verdict)`. Its docstring lists what it cannot see (`:20-35`), among them "launches inside third-party libraries (Playwright's driver, webbrowser)".
- Hidden pins this slice meets:
  - K1 pins `TICKET_EFFECTS` and `TICKET_OPERATIONS` (`tests/test_ad1346_admission_tickets.py:145-146`).
  - TR6 computes the per-day bound from `len(TICKET_OPERATIONS)` and asserts it stays below the limit over 35 days (`tests/test_ad1346_admission_ticket_record.py:281-282`); it does not pin the number.
  - SK7 pins the set of `check_at` callers (`:506-507`).
  - T16 pins the `src` files that name `admission_service` and those that import `probos.admission` (`tests/test_ad1346_admission_service.py:612-625`).

## 2. Solution

- **The effect.** `EFFECT_SUBPROCESS = "subprocess"` is appended to `TICKET_EFFECTS`. `TICKET_OPERATIONS`, `hold`'s scope and `check`'s accepted effects follow. It is not a seam.
- **Five sinks.** Five functions gain one statement before a launch that an agent or model text directs: `check_at(getattr(getattr(self, "_runtime", None), "admission_service", None), effect=EFFECT_SUBPROCESS, presented_id=...)`. The five: `ShellCommandAgent._run_command`, `RedTeamAgent._verify_run_command`, `CodeSearchAgent._search_rg`, `ScoutAgent._search_github` and `RunCommandTool.invoke`. With no service, or anything but an exact `AdmissionService`, `check_at` does nothing.
- **The census.** `tests/fixtures/ad1346_effect_census.py` reads BF-892's scan and gives each of its 31 (file, function) keys a launch count and one coverage:
  - `Sink`: 5 functions, 7 launches;
  - `System("system:ship_computer", ...)`: 14 functions, 16 launches;
  - `OutsideRuntime`: 4 functions, 5 launches, in `probos.__main__` and the doctor package;
  - `Pending("M3e2", ...)`: 8 functions, 11 launches.
- **The guard** (EC2 to EC7). A new or removed launch site that BF-892's scan finds, or a changed count, fails it. So does a sink row whose check is missing, malformed or after its launch; a sink's separate launching function referenced elsewhere in its file; a system row's principal or a literal `system:` presented id off the allowlist, or an allowlist entry the census does not name; an absolute import of a command-line module by a runtime module; and an effect class delivered without a `TICKET_EFFECTS` member.
- **The crossing test** (EC9) and **the golden test** (EC10) drive real code with each launch replaced, so no process starts.
- **The hand-off** (A2, §7.5). `ProbOSRuntime.create_pool` passes `runtime=self` to a shell or code-search pool made without a `runtime` keyword, as `create_agent_fleet` makes both, and `_spawn_red_team` passes `runtime=self` to each red team agent. SW1 and SW2 count those agents' sink checks in a real `TicketRegistry`.

  - avatars, voice, the episodic probe, the credential helper;

def census_problems(found: dict[tuple[str, str], int], listed: dict[tuple[str, str], tuple[int, object]]) -> list[str]:
    """What differs between launches found and rows listed: unlisted sites, stale rows, then differing counts."""
    problems = [f"unlisted launch site {site}" for site in sorted(found.keys() - listed.keys())]
    problems += [f"stale row {site}" for site in sorted(listed.keys() - found.keys())]
    problems += [
        f"{site}: {found[site]} launches, the row says {listed[site][0]}"
        for site in sorted(found.keys() & listed.keys())
        if found[site] != listed[site][0]
    ]
    return problems


def references_outside(tree: ast.Module, name: str, allowed: tuple[str, ...]) -> list[tuple[str, int]]:
    """(enclosing function, line) of each reference to ``name``, as an attribute or a bare name, outside ``allowed``."""
    found: list[tuple[str, int]] = []

    def walk(node: ast.AST, scope: tuple[str, ...]) -> None:
        for child in ast.iter_child_nodes(node):
            if isinstance(child, (ast.ClassDef, ast.FunctionDef, ast.AsyncFunctionDef)):
                walk(child, (*scope, child.name))
                continue
            qualname = ".".join(scope)
            named = (isinstance(child, ast.Attribute) and child.attr == name) or (isinstance(child, ast.Name) and child.id == name)
            if named and qualname not in allowed:
                found.append((qualname or "<module>", child.lineno))
            walk(child, scope)

    walk(tree, ())
    return found


def system_principal_literals(sources: dict[str, str]) -> set[str]:
    """The ``system:`` strings a ``shadow_at``, ``hold_at`` or ``check_at`` call passes as a literal ``presented_id``."""
    found: set[str] = set()
    for rel, source in sources.items():
        if not any(helper in source for helper in _SEAM_HELPERS):
            continue
        for node in ast.walk(ast.parse(source, filename=rel)):
            if not isinstance(node, ast.Call):
                continue
            func = node.func
            callee = func.attr if isinstance(func, ast.Attribute) else func.id if isinstance(func, ast.Name) else ""
            if callee not in _SEAM_HELPERS:
                continue
            for keyword in node.keywords:
                value = keyword.value
                if (
                    keyword.arg == "presented_id" and isinstance(value, ast.Constant) and isinstance(value.value, str)
                    and value.value.startswith(SYSTEM_PRINCIPAL_PREFIX)
                ):
                    found.add(value.value)
    return found


def outside_importers(sources: dict[str, str]) -> list[tuple[str, int]]:
    """(file, line) of each absolute import of ``probos.__main__`` or the doctor package by a module not under
    ``OUTSIDE_RUNTIME``."""
    found: list[tuple[str, int]] = []
    for rel, source in sources.items():
        if rel.startswith(OUTSIDE_RUNTIME) or ("__main__" not in source and "doctor" not in source):
            continue
        for node in ast.walk(ast.parse(source, filename=rel)):
            if isinstance(node, ast.Import):
                names = [alias.name for alias in node.names]
            elif isinstance(node, ast.ImportFrom) and node.level == 0 and node.module is not None:
                names = [node.module] + ([f"probos.{alias.name}" for alias in node.names] if node.module == "probos" else [])
            else:
                continue
            if any(name == module or name.startswith(f"{module}.") for name in names for module in _OUTSIDE_MODULES):
                found.append((rel, node.lineno))
    return found
