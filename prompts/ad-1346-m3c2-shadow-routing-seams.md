## 1. Problem

- Twelve of the sixteen `STOP_CHECK_SITES` (`tests/fixtures/ad1343_seam_registry.py:21-39`) hold no shadow statement on the build base; `SHADOW_PENDING` (`:50-63`) lists them. Six belong to this slice: `:51-56`, each marked `"AD-1346 M3c2"`; the other six (`:57-62`) are marked `"AD-1346 M3c3"`. After this slice ten hold a statement and six stay pending.
- #1601 evidence 1 (coverage) and 4 (parity) and #1604 property 12 (the golden test) cannot be met while these six routing seams are unshadowed. Each is a place agent work starts:
  - the proactive cycle (`src/probos/proactive.py:1018`);
  - Ward Room routing (`src/probos/ward_room_router.py:644`);
  - the Captain's DM route (`src/probos/routers/agents.py:2963`);

  - the browser action a DM reply proposes inline (`src/probos/cognitive/dm/reply_pipeline.py:1054`).
- Three of the six checks are written inline in an `if` (`proactive.py:1018`, `thread_fanout.py:657`, `reply_pipeline.py:1054`). Their result is not held in a name a statement could read.
- `WardRoomRouter` holds no runtime. It reaches its stop gate only through its constructor (`ward_room_router.py:41`, `:58`, `:72`), which `startup/finalize.py:5573-5587` calls.

## 2. Solution

- **Statements.** One `shadow_at(...)` statement after each of the six checks, before the site acts on the result, with no await between. The statement carries `refused=<the check's record> is not None`. At the three inline checks, the check's call moves unchanged into a local, `_stopped`, so it is still evaluated once.
- **Reach.** Each site reaches the service the way it reaches its stop gate:
  - the proactive cycle reads `admission_service` from the runtime once per cycle, beside `agent_stops`;
  - the three route functions and the inline step read it with `getattr` on the runtime they already hold;
  - `WardRoomRouter` takes it as a constructor keyword beside `agent_stops`, and `finalize.py` passes it.
  - A None service, or any object that is not exactly an `AdmissionService`, is passed over by `shadow_at` (`seam.py:21-22`).
- **Requests.** Each statement uses a work kind M3a already defined for its seam (`taxonomy.py:25-37`: `proactive_cycle`, `ward_room_notice`, `direct_message`, `group_turn`, `browser_action`). No work kind and no seam is added.
- **Census.** The six rows move to `SHADOW_SITES`. 9a also requires each registered work kind to be in `WORK_KINDS`.
- **T16.** The expected sets grow by the shadowed-site files and `finalize.py`. The router pin becomes: the only routers that name the service or import the package are the three shadowed ones, and none is a module of a property 11 route.
- **G3** (one real boot): each of the six records today's outcome beside its shadow verdict.
- **G4** (two real boots, switch on and off): the calls G4 makes at the six give byte-identical answers.

async def _drive(rt: ProbOSRuntime, monkeypatch: pytest.MonkeyPatch) -> tuple[dict[str, Any], dict[str, int], str, str]:
    """A proactive cycle, a fan-out round, an ACK and an inline action with no order, then all six seams under a Captain's
    stop: the answers, the refusals the order counted at each routing seam, the normalised text and the agent."""
    loop = rt.proactive_loop
    assert loop is not None and rt.ward_room_router is not None, "premise: the boot has the proactive loop and the Ward Room router"
    await loop.stop()  # the loop's own task would run cycles of its own; only the cycles below run
    monkeypatch.setattr(rt.config.proactive_cognitive, "stagger_enabled", False)
    swept: list[str] = []

    async def _sweep(agent: Any, runtime: Any) -> None:
        swept.append(agent.id)

    async def _think(agent: Any, rank: Any, trust_score: float) -> None:
        return None

    monkeypatch.setattr(loop, "_check_unread_dms", _sweep)
    monkeypatch.setattr(loop, "_think_for_agent", _think)
    await loop._run_cycle()
    offered = set(swept)
    crew = _certified_crew(rt, offered)
    answers: dict[str, Any] = {
        "fan_out_admitted": await _fan_out(rt, crew.id),
        "ack_admitted": await _ack(rt, crew.id),
        "inline_admitted": await _inline(rt, crew.id),
    }
    record = (await rt.agent_stops.issue_stop(crew.id, reason=_REASON)).record
    before = rt.agent_stops.refused_counts(record.stop_id)
    swept.clear()
    await loop._run_cycle()
    answers["proactive_refused"] = [crew.id in swept, set(swept) == offered - {crew.id}]
    answers["ward_room_refused"] = await _ward_room(rt, crew.id)
    answers["dm_refused"] = await _dm(rt, crew.id)
    answers["fan_out_refused"] = await _fan_out(rt, crew.id)
    answers["ack_refused"] = await _ack(rt, crew.id)
    answers["inline_refused"] = await _inline(rt, crew.id)
    after = rt.agent_stops.refused_counts(record.stop_id)
    counted = {seam: after.get(seam, 0) - before.get(seam, 0) for _, seam in _ROUTING}
    text = json.dumps(answers, sort_keys=True, default=repr)
    for value, mark in ((record.stop_id, "<stop>"), (record.sender_detail()["since"], "<since>"), (crew.id, "<agent>")):
        text = text.replace(value, mark)
    return answers, counted, text, crew.id
