## Solution Overview

AD-477 in roadmap.md (line 4207) lists 6 naval organization capabilities. Heavy overlap exists with already-shipped systems:

- **(1) Qualification Programs** — overlaps with AD-566 (Crew Qualification Battery), AD-539 (Gap → Qualification Pipeline), AD-595e (Qualification Gate Enforcement). Extending those is its own AD.
- **(4) 3M System** + **(5) Damage Control Organization** — large engineering systems each warranting their own AD.
- **(6) SORM** — Standing Orders Manual evolution; large governance scope.

**v1 ships 2 of 6 capabilities** (per convention #14 aggressive pre-deferral) — the truly NEW generative surfaces with no existing-system conflict:

1. **Captain's Log** — synthesized daily narrative aggregating episodic memory highlights + Ward Room activity + dream consolidation summaries. One Markdown document per day at `data/captains_log/YYYY-MM-DD.md`. Generated by background task at end-of-day or on-demand via runtime API.
2. **Plan of the Day** — auto-generated morning operations summary aggregating active WorkItems, Ward Room thread queue, alert conditions, scheduled duties. One Markdown document per day at `data/plan_of_day/YYYY-MM-DD.md`.

**Deferred to grandchildren:**
- AD-477b: Qualification Programs (extends AD-566 with rank-transition requirements). Forcing function: when AD-566's qualification system gets concrete pass/fail criteria for cross-rank promotion.
- AD-477c: 3M System (planned preventive maintenance). Forcing function: when fleet operational scale demands it.
- AD-477d: Damage Control Organization (5-phase protocol). Forcing function: when alert-condition response needs structured procedure.
- AD-477e: SORM (Ship's Organization and Regulations Manual). Forcing function: governance evolution AD.

### Section 2 — `CaptainsLogService`

```python
class CaptainsLogService:
    """Synthesizes daily narrative from episodic memory + Ward Room + dreams."""

    def __init__(self, runtime: Any, config: CaptainsLogConfig) -> None:
        self._runtime = runtime
        self._config = config
        self._task: asyncio.Task | None = None  # convention #17: instance state

    async def generate_for_date(self, date: datetime.date) -> str:
        """Generate Captain's Log Markdown for the given date.

        Aggregates:
        - Top N episodes from episodic memory (importance >= threshold) for the date
        - Ward Room thread highlights (activity count, top topics)
        - Dream consolidation summaries (if dreaming_engine has run)
        - Active work item summary
        Returns the Markdown content as a string. Caller writes to disk.
        """

    async def write_to_disk(self, date: datetime.date) -> Path:
        """Generate + write to data/captains_log/YYYY-MM-DD.md. Emits CAPTAINS_LOG_GENERATED."""

    async def start(self) -> None:
        """Start background task that runs at end-of-day."""

    async def stop(self) -> None:
        """Cancel background task."""
```

### Section 3 — `PlanOfDayService`

```python
class PlanOfDayService:
    """Generates morning operations summary."""

    def __init__(self, runtime: Any, config: PlanOfDayConfig) -> None:
        self._runtime = runtime
        self._config = config
        self._task: asyncio.Task | None = None

    async def generate_for_date(self, date: datetime.date) -> str:
        """Generate Plan of the Day Markdown.

        Aggregates:
        - Active WorkItems via runtime.work_item_store.list_work_items(status="pending")
        - Ward Room thread queue depth
        - Current alert conditions
        - Scheduled duties for the day
        Returns Markdown content. Caller writes to disk.
        """

    async def write_to_disk(self, date: datetime.date) -> Path:
        """Generate + write to data/plan_of_day/YYYY-MM-DD.md. Emits PLAN_OF_DAY_GENERATED."""

    async def start(self) -> None:
        """Start background task that runs at start-of-day."""

    async def stop(self) -> None:
        """Cancel background task."""
```
