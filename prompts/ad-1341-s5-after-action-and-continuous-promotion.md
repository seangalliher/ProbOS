## 1. Problem

#1569 Decision 2: promotion runs "continuously, as a dream step for entries that meet their criterion"; Decision 7: "Continuous promotion is behind a flag at first, so the criteria can be calibrated." The Captain's amendment (comment 1) adds:
- item 2: "an **after-action report** (AAR, the naval 'hot wash') after significant events: a fault, a failed or abandoned task, a Captain-flagged event, a red-team finding";
- item 3: "A lesson goes through the chain of command, for example the department chief and then the Counselor or XO, before promotion to the Ship's Archive. The Captain can veto."

Four things are missing:
1. **No after-action report.** S4's only lesson source is the exit note before a reset.
2. **No chain-of-command review.** S4's D12 moved it here (register F-630).
3. **No continuous promotion.** The archive is written only by the offline `probos reset`, under the AD-816 pidfile.
4. **An in-vessel writer is new.** No in-vessel writer has ever had to coexist with `/forget`. S3's R3 (F-632) is a promotion landing between an erasure's archive check and its evict. F-633: once lessons are archived while their episodes live, S3's archive check has something to protect.

## 2. Solution overview

- **M1, the format and the rule.**
  - `knowledge/lessons.py` gains the after-action report: its path, keyed by billet and the Captain's flag time; its origin line; its envelope; and `after_action_review_ok`, the one rule of the chain-of-command review.
  - `SourceKind` gains `AFTER_ACTION_REPORT`.
  - `archive_promotion` gains `_after_action_record`: S4's exit-note rule plus the review, so only an endorsed report is a source, at the reset or continuously.
  - The AD-754 citation read (`exit_note_citations`) also reads `after-action/`, under the same rule.
  - `_stored_text` converts only scalars (register F-661, which is due "for the next slice that edits `archive_promotion.py`").
- **M2, the turn and the review.**
  - A new `probos/after_action.py` and a console command, `/after-action CALLSIGN: SUBJECT` (console only).
  - The named agent gets one bounded turn: S4's bounded `direct_message` from the Captain, with its recent episodes by handle. It answers in the lessons format.
  - The chain of command then reviews the report, by billet: the author's superior, then the Counselor, or the first officer when the Counselor wrote it or already reviewed it. Each reviewer gets one bounded turn: ENDORSE or RETURN.
  - The report is written once, with its review in the envelope.
- **M3, continuous promotion.**
  - A default-off `archive_promotion` config section.
  - `archive_promotion.promote_settled` runs the reset's own plan. It promotes a source only once it has settled (24 h after its last update by default), at most 8 new entries per cycle.
  - A source that cites episodes is promoted only inside BF-939's erasure lock, and only when every cited episode is still live.
  - `knowledge/continuous_promotion.py` builds the step and wires it. `DreamingEngine.dream_cycle` runs it once per full cycle, before the no-episode return; a failure is logged and never fails a dream.
  - `erasure.exclusive_with_erasure` exposes BF-939's lock.
- **M4.** Trackers.

`probos reset` does not change. It still promotes everything settled or not, and its plan now includes endorsed after-action reports. There is no schema change, no new event type and no new API route.

## 3. Decisions

- **D1 (premises).** §0. S1's decisions (key, marker, C1, pidfile, store lock), S2's label, S3's review, veto and citation check, S4's format, exit notes and stand-down, and BF-939's lock all stand.
- **D2 (the triggers).** Ranked:
  - **(A) chosen: the Captain's flag.** `/after-action CALLSIGN: SUBJECT` at the vessel's console. This is a real trigger: the Captain's order, needing no new event, payload or detector. It covers every event the amendment names, because the Captain can flag a fault, a failed or abandoned task, or a red-team finding by name. The subject is the Captain's one line (at most 160 characters). It goes in the prompt and the envelope, not in the archived body (D4).
  - (B) automatic triggers from emitted events, as listed in §0: **deferred** (register R1).
    - Each one starts two or three model turns with nobody watching. Each needs its own per-day budget and a persisted cursor, so a restart does not ask again or skip.
    - Each needs a rule for whom to ask: `FAULT_RESOLVED`'s payload names no agent (`fault_report.py:973-979`), and a red-team campaign has no single author.
    - None of this is needed to prove the format, the review or the promotion. The seam is ready for it: `run_after_action` takes the author, subject and flag time from any caller.
    - The Captain may overrule this ordering.
  - (C) a detector in the dream step that asks agents unprompted: rejected for this slice. It would spend model turns inside a cycle that is otherwise bounded by local work, and the cycle's cadence is idle-time, which is not the event's time.
- **D3 (the turn).** S4's bounded turn, unchanged: a `direct_message` intent `{"text", "from": "captain", "session": False, "bounded_turn": True}` through `runtime.intent_bus.send`, answered inline on the single-pass path. No tool-calling loop runs, so nothing it starts outlives it (S4 7.9a). The author is shown up to 12 of its own most recent episodes by handle (S4's `_offer`, exported as `offer_episodes`). It may cite only those. Writing is optional (`NO NOTES`).
- **D4 (the report: its shape and where it is stored).** Ranked:
  - **(A) chosen: a Ship's Records document** at `after-action/{timeline}/{agent_type}-{flagged}.md`. `flagged` is the UTC time of the Captain's flag, `YYYYMMDDTHHMMSSZ`, lower-cased in the path.
    - Body: the origin line ("After-action report by {callsign} ({agent_type}) of the crew of timeline {timeline}. A record, not a memory.") followed by the rendered lesson. It is checked by `after_action_lesson`, the same canonical-body rule as S4's A2.
    - Frontmatter: `author` (the callsign), `classification: ship`, `status: submitted`, and the envelope `after_action: {version: 1, timeline_id, callsign, agent_type, author_did, flagged_at, subject, source_episode_ids, review}`.
    - Why Ship's Records again: S1's plan, S3's `pending` and `veto`, S4's strict citation read and S4's lessons parser all work by records path and need no change. The Captain reads a report as a Markdown file.
    - Why the subject is not in the body: S4's L6 budget fits a whole note at every bound into one Oracle tool entry (1,200 characters). This origin line is 16 characters shorter than the exit note's, and the title ("After-action report of X") is 9 longer, so a whole report fits (A7 pins it). A 160-character subject in the body would not fit.
  - (B) a notebook entry: rejected (S4 D7 B: private by default, mixed with working notes).
  - (C) a new store: rejected (a new `.db`, a baseline row, backup coverage, and a second reader).
- **D5 (the chain-of-command review: who, how, and what admits a report).**
  - **Stages, by billet, each resolved when it is reached** (`chain_of_command_reviewers`, called again before each stage on the crew and its identities as they are then; Amendment A3, round 1's B1: a billet filled or refilled during the author's or the superior's turn is asked of its new holder, never recorded `vacant` or asked of a slot that left; a billet that cannot be resolved is `not_reviewed`, so the report is withheld):
    - `superior`: whoever fills the post the author's post `reports_to`. That is a department chief for an officer, and the first officer (XO) for a chief.
    - `counselor_or_xo`: whoever fills `counselor`, or, if that is the author's billet or the superior's, `first_officer`.
    - A billet is filled by the first crew agent of its type, in crew order (S4's billet rule), that has a callsign, agent type and DID the envelope can hold.
  - **Vacancy.** A billet with no such agent is `vacant`. A post reporting to the captain has no crew superior: the captain is not a crew agent. The author never reviews its own report: its billet is skipped at both stages.
  - **The answers.** Each reviewer gets one bounded turn with the report's text and answers `ENDORSE` or `RETURN` (`parse_review`: the first word, emphasis and punctuation allowed). Anything else, no reply, a failure or a late reply counts as `not_reviewed`. A `returned` or `not_reviewed` stage ends the review; later stages are recorded as `not_reviewed` and not asked.
  - **What admits a report** (`after_action_review_ok`, the one rule): exactly one entry per stage, in order. Each stage is `endorsed`, by a reviewer whose identity can stand in the envelope, or `vacant`. **At least one stage is endorsed.** No endorser is the author's billet, and no billet endorses twice. **This validates the recorded review; it does not authenticate it** (Amendment A3, round 1's A1): a well-formed envelope naming real billets, written by any writer of the stored document, is admitted, and only a malformed one is withheld (R8).
  - **Ranked:** (a) chosen: at least one endorsement; (b) both stages vacant passes to the Captain's opt-out review alone (S4 D12 A): rejected, because the review the Captain asked for would silently become no review on a ship with no chiefs; (c) unanimous with no vacancy allowed: rejected, because a vacant Counselor post would bar every lesson. **The Captain may overrule (a).**
  - **Exit notes keep S4's D12 (A)**, the Captain's opt-out review at the reset. The reason is S4's: their reviewers are writing their own notes inside one bounded window before a reset. The Captain may overrule this ordering (register R2).
  - **The Captain's veto and the default remain.** `probos archive pending` lists every endorsed report and `probos archive veto PATH` keeps one out. The reset still promotes everything that meets its criterion, an endorsed report included. A returned report stays in Ship's Records as a record; neither path ever archives it.
- **D6 (when the review runs).** Ranked:
  - **(A) chosen: inline, in the same bounded window as the author's turn, and the report is written once afterwards** with its review in the envelope. A crew document is never rewritten by a service, no pending-review state is stored, and the review cannot be lost between steps.
  - (B) the report is written first and reviewed later by the dream step: rejected. The service would rewrite the crew's document in place (an AD-550 upsert that replaces its author: register F-657), or would need review documents of its own and a listing that joins them.
  - (C) separate review documents: rejected (the same listing join, and a third directory for the AD-754 read).
- **D7 (the bounds of `/after-action`).** `AFTER_ACTION_TURN_SECONDS = 180.0` per turn and `AFTER_ACTION_WINDOW_SECONDS = 600.0` for the author's turn, both reviews and the write. That is at most three turns, in sequence. Each turn has one deadline, `min(start + 180, window end)`; the author's recall spends from it, and a reply must meet it. No write begins once the window has closed. A report already at its path is never written over, and then nobody is asked. These are module constants, as S4's are (register R13). `/after-action` joins `_BLOCKED_COMMANDS`: the HXI chat and the channel adapters reach slash commands without the Captain's console (S4 D2).
- **D8 (continuous promotion: where it runs, and its flag).** Ranked:
  - **(A) chosen: a dream step**, run once per full `dream_cycle`, right after Step 0 and before the no-episode return. What it promotes is Ship's Records, not this cycle's episodes. This is the issue's own design. The engine is one per ship and runs at idle time. Shutdown never runs a full cycle (§0), so the step never races the archive's close.
  - (B) the duty schedule: rejected. Duties are crew agents' turns on a cron (S4 D3 E, `duty_schedule.py:4`, `:173-197`, not re-read). Promotion is a Ship's Computer service with no agent turn.
  - (C) its own asyncio loop: rejected. It would be one more lifecycle owner to start and stop.
  - **The flag is a code default in `SystemConfig`:**
    - The section is `archive_promotion: ArchivePromotionConfig` with `enabled: bool = False`, `settle_hours: float = 24.0` (0 to 720) and `max_per_cycle: int = 8` (1 to 100).
    - It is a new section, not new fields on `ArchiveConfig`, whose dump AD-1270 E2f pins.
    - `config/system.yaml` is not edited. The AD-1152 default-config dump gains one `pop` (7.14).
    - Wiring checks `enabled is True` and `archive.enabled is True` by identity, so a test double's attribute wires nothing.
  - **Cadence:** the scheduler's (idle threshold and dream interval; `force_dream` and the surgeon's call included; register R16).
- **D9 (what is promoted, and at which classification).** The reset's own plan (`plan_promotion`) and rules, so continuous promotion archives nothing the reset would not.
  - C1 holds: only `ship` and `fleet`, the classification S1's C1 decision fixed. Re-read here: the Oracle's archive tier has no reader filter (`archive_store.py:85-87`), so nothing narrower reaches a later crew.

```python
# --- AD-1341 S5 (#1569): the after-action report and its chain-of-command review -------------------------------------

#: Where after-action reports live in Ship's Records, the frontmatter key of their envelope, its version and the status
#: a report is written at.
AFTER_ACTION_DIR: Final = "after-action"
AFTER_ACTION_KEY: Final = "after_action"
AFTER_ACTION_VERSION: Final = 1
AFTER_ACTION_STATUS: Final = "submitted"
#: The longest subject the Captain may flag, one line. It stands in the envelope and the prompt, never in the body
#: (D4: the Oracle-entry budget of ``LESSON_MAX_CHARS``).
AFTER_ACTION_SUBJECT_MAX_CHARS: Final = 160

#: The chain-of-command review (#1569 comment 1, item 3), in order: the author's superior in the chain of command (a
#: department chief, or the first officer for a chief), then the Counselor, or the first officer (XO) when the Counselor
#: wrote the report or is the superior.
REVIEW_STAGES: Final = ("superior", "counselor_or_xo")
REVIEW_ENDORSED: Final = "endorsed"
REVIEW_RETURNED: Final = "returned"
REVIEW_NOT_REVIEWED: Final = "not_reviewed"
REVIEW_VACANT: Final = "vacant"

_FLAGGED_AT = re.compile(r"\d{8}T\d{6}Z")


def after_action_path(timeline_id: str, agent_type: str, flagged_at: str) -> str:
    """The one Ship's Records path of a report: ``after-action/{timeline}/{agent_type}-{flagged}.md`` (S5 D4, D12).

    Keyed by billet and by the moment the Captain flagged the event (UTC, ``YYYYMMDDTHHMMSSZ``, lower-cased in the
    path), as exit notes are keyed by billet. ValueError for a stamp in any other form, or for a timeline or agent type
    with no letter or digit.
    """
    if type(flagged_at) is not str or _FLAGGED_AT.fullmatch(flagged_at) is None:
        raise ValueError("AD-1341 S5: flagged_at must be a UTC stamp YYYYMMDDTHHMMSSZ")
    timeline, billet = _slug(timeline_id, "timeline_id"), _slug(agent_type, "agent_type")
    return f"{AFTER_ACTION_DIR}/{timeline}/{billet}-{flagged_at.lower()}.md"


def after_action_header(callsign: str, agent_type: str, timeline_id: str) -> str:
    """A report's fixed first line: who wrote it, of which crew, and that it is a record, not a memory."""
    return (
        f"After-action report by {callsign} ({agent_type}) of the crew of timeline {timeline_id}. "
        "A record, not a memory."
    )


def after_action_body(callsign: str, agent_type: str, timeline_id: str, lesson: LessonLearned) -> str:
    """A report's body: its origin line, then the rendered lesson. Nothing else, the Captain's subject included."""
    return f"{after_action_header(callsign, agent_type, timeline_id)}\n\n{lesson.render()}"


def after_action_lesson(callsign: str, agent_type: str, timeline_id: str, content: object) -> LessonLearned | None:
    """The lesson of a canonical report body, or None: the one rule for the writer and the promotion (as S4's A2)."""
    lesson = parse_lesson(content)
    if lesson is None or content != after_action_body(callsign, agent_type, timeline_id, lesson):
        return None
    return lesson


def after_action_review_ok(review: object, author_agent_type: object) -> bool:
    """AD-1341 S5 (D5): whether a report's recorded chain-of-command review admits it to the Ship's Archive.

    Exactly one entry per stage of ``REVIEW_STAGES``, in order. Each is ``endorsed`` by a reviewer whose callsign, agent
    type and DID can stand in the envelope, or ``vacant`` (no crew agent fills the billet). At least one stage is
    endorsed, no endorser holds the author's billet, and no billet endorses twice. A returned or unreviewed stage, or
    anything else, never admits the report. The one rule for the writer's report, the promotion and the erasure's read.
    """
    if type(review) is not list or len(review) != len(REVIEW_STAGES):
        return False
    endorsers: set[str] = set()
    for stage, entry in zip(REVIEW_STAGES, review, strict=True):
        if type(entry) is not dict or entry.get("stage") != stage:
            return False
        outcome = entry.get("outcome")
        if outcome == REVIEW_VACANT:
            continue
        if outcome != REVIEW_ENDORSED:
            return False  # D5: a returned or unreviewed stage keeps the report out of canon
        reviewer = entry.get("agent_type")
        if not (
            is_exit_note_text(entry.get("callsign"), EXIT_NOTE_CALLSIGN_MAX_CHARS)
            and is_exit_note_text(reviewer, EXIT_NOTE_AGENT_TYPE_MAX_CHARS)
            and is_exit_note_text(entry.get("did"), EXIT_NOTE_DID_MAX_CHARS)
        ):
            return False
        if reviewer == author_agent_type or reviewer in endorsers:
            return False  # D5: nobody reviews their own report, and one billet endorses once
        endorsers.add(reviewer)
    return bool(endorsers)  # D5: a report no one in the chain endorsed never reaches canon on its own
```

```python
def chain_of_command_reviewers(
    author: CrewMember, crew: Sequence[CrewMember], ontology: Any,
) -> tuple[tuple[str, CrewMember | None], ...]:
    """AD-1341 S5 (D5): each review stage and the crew agent who fills it now, or None when the billet is vacant.

    By billet, resolved at the time of the review: the superior is whoever fills the post the author's post reports to;
    the second stage is whoever fills the first of ``SECOND_REVIEW_POSTS`` that is neither the author's billet nor the
    superior's. A billet is filled by the first crew agent of its type, in crew order, whose identity the envelope can
    hold. Nobody reviews their own report. With no ontology every stage is vacant. ``after_action_vessel`` has
    ``run_after_action`` call it again before each stage, on the crew as it is then (Amendment A3).
    """
    first_of_type: dict[str, CrewMember] = {}
    for member in crew:
        if _can_review(member):
            first_of_type.setdefault(member.agent_type, member)  # one turn per billet, in crew order (S4's rule)

    def filling(post_id: object) -> CrewMember | None:
        if ontology is None or type(post_id) is not str or not post_id:
            return None
        for assignment in sorted(ontology.get_agents_for_post(post_id), key=lambda item: item.agent_type):
            member = first_of_type.get(assignment.agent_type)
            if member is not None and member.agent_type != author.agent_type:
                return member
        return None

    post = ontology.get_post_for_agent(author.agent_type) if ontology is not None else None
    superior = filling(post.reports_to if post is not None else None)
    second: CrewMember | None = None
    for post_id in SECOND_REVIEW_POSTS:
        candidate = filling(post_id)
        if candidate is not None and (superior is None or candidate.agent_type != superior.agent_type):
            second = candidate
            break
    return ((REVIEW_STAGES[0], superior), (REVIEW_STAGES[1], second))

def parse_review(reply: object) -> str:
    """A reviewer's answer: ``endorsed``, ``returned``, or ``not_reviewed`` for anything else (D5)."""
    if type(reply) is not str:
        return REVIEW_NOT_REVIEWED
    match = _REVIEW_REPLY.match(reply.strip())
    if match is None:
        return REVIEW_NOT_REVIEWED
    return REVIEW_ENDORSED if match.group(1).lower() == "endorse" else REVIEW_RETURNED


async def run_after_action(
    author: CrewMember,
    *,
    subject: str,
    flagged_at: str,
    reviewers: Reviewers,
    ask: Ask,
    recall: Recall,
    records: RecordsStore,
    timeline_id: str,
    turn_seconds: float = AFTER_ACTION_TURN_SECONDS,
    window_seconds: float = AFTER_ACTION_WINDOW_SECONDS,
    clock: Callable[[], float] = time.monotonic,
) -> AfterActionReport:
    """Ask ``author`` for one report on ``subject``, have the chain review it, and write it once (D3 to D7).

    ``reviewers`` returns one ``(stage, member or None)`` per ``REVIEW_STAGES`` entry, in order
    (``chain_of_command_reviewers`` on the crew as it is then). It is called before anyone is asked, to check that
    shape, and again before each stage, so a stage is asked of whoever holds its billet after every earlier turn; a
    stage whose holder cannot be read is not reviewed (D5, Amendment A3). ``ask`` delivers a prompt and returns the
    reply (None for no reply); ``recall``
    returns the author's most recent episodes. Each turn has one deadline, ``turn_seconds`` after it begins and never
    past the window, that its reply must meet. The window bounds every turn and the write, and no write begins once it
    has closed. A report already at its path is never written over, and then nobody is asked.

    Raises ``AfterActionRefused`` (nobody asked, nothing written) for a subject, identity, timeline or flag that cannot
    stand in a report, and ``ValueError`` for a bound that is not positive or reviewers not in stage order. Nothing a
    turn does raises.
    """
    if turn_seconds <= 0 or window_seconds <= 0:
        raise ValueError("AD-1341 S5: an after-action report's bounds must be positive")
    resolved = reviewers()  # the shape is checked before anyone is asked; each stage resolves its holder again (D5)
    if [stage for stage, _member in resolved] != list(REVIEW_STAGES):
        raise ValueError("AD-1341 S5: one reviewer entry per review stage, in order")
    if not is_exit_note_text(subject, AFTER_ACTION_SUBJECT_MAX_CHARS):
        raise AfterActionRefused(
            f"The subject must be one line of at most {AFTER_ACTION_SUBJECT_MAX_CHARS} characters."
        )
    if not exit_note_provenance_ok(timeline_id, author.callsign, author.agent_type, author.did):
        raise AfterActionRefused("The agent or this vessel has no identity a report could carry.")
    try:
        path = after_action_path(timeline_id, author.agent_type, flagged_at)
    except ValueError as exc:
        raise AfterActionRefused(f"The report cannot name a records path: {exc}") from exc

    def _done(outcome: AfterActionOutcome, at: str = "", reviews: Sequence[ReviewResult] = ()) -> AfterActionReport:
        return AfterActionReport(author.callsign, author.agent_type, outcome, at, tuple(reviews))

    present = path_presence(records.repo_path / path)
    if present is not False:  # a report is never written over, nor where that cannot be ruled out
        return _done(AfterActionOutcome.ALREADY_WRITTEN, path) if present else _done(AfterActionOutcome.FAILED)
    deadline = clock() + window_seconds

    async def _turn(member: CrewMember, prompt: str, turn_deadline: float) -> tuple[str, str | None]:
        """One bounded turn: ("answered", reply), ("timed_out", None) or ("failed", None). Never raises."""
        remaining = turn_deadline - clock()
        if remaining <= 0:
            return "timed_out", None
        try:
            reply = await asyncio.wait_for(ask(member, prompt), timeout=remaining)
        except TimeoutError:
            return "timed_out", None
        except Exception:  # log-and-degrade: a failed turn never stops the report or the console
            logger.warning("AD-1341 S5: %s's after-action turn failed", member.callsign, exc_info=True)
            return "failed", None
        if clock() > turn_deadline:  # a reply after the turn's deadline counts for nothing
            return "timed_out", None
        return "answered", reply

    turn_deadline = min(clock() + turn_seconds, deadline)
    try:
        episodes = await asyncio.wait_for(recall(author), timeout=max(0.001, turn_deadline - clock()))
    except Exception:  # log-and-degrade: the turn offers no episodes, so the report cites none
        logger.warning(
            "AD-1341 S5: %s's recent episodes could not be read; the turn offers none", author.callsign, exc_info=True,
        )
        episodes = ()
    offered, shown = offer_episodes(episodes)
    status, reply = await _turn(author, after_action_prompt(author.callsign, subject, shown), turn_deadline)
    if status != "answered":
        return _done(AfterActionOutcome.TIMED_OUT if status == "timed_out" else AfterActionOutcome.FAILED)
    if reply is None:
        return _done(AfterActionOutcome.NO_REPLY)
    if is_declined(reply):
        return _done(AfterActionOutcome.DECLINED)
    lesson = parse_lesson(reply)
    if lesson is None:
        return _done(AfterActionOutcome.NOT_IN_FORMAT)
    body = after_action_body(author.callsign, author.agent_type, timeline_id, lesson)
    if after_action_lesson(author.callsign, author.agent_type, timeline_id, body) != lesson:
        logger.error("AD-1341 S5: %s's report would not pass the promotion's rule; nothing is written", author.callsign)
        return _done(AfterActionOutcome.FAILED)
    cited = parse_citations(reply, offered)

    reviews: list[ReviewResult] = []
    for stage in REVIEW_STAGES:
        if reviews and reviews[-1].outcome in (REVIEW_RETURNED, REVIEW_NOT_REVIEWED):
            reviews.append(ReviewResult(stage, REVIEW_NOT_REVIEWED))  # D5: the review ended at the stage before
            continue
        try:
            reviewer = dict(reviewers()).get(stage)  # D5 (Amendment A3): the billet's holder now, after every earlier turn
        except Exception:  # log-and-degrade: an unknown holder is not a vacancy, so the stage is not reviewed
            logger.warning(
                "AD-1341 S5: the %s billet for %s's report could not be resolved; that stage is not reviewed", stage,
                author.callsign, exc_info=True,
            )
            reviews.append(ReviewResult(stage, REVIEW_NOT_REVIEWED))
            continue
        if reviewer is None or not _can_review(reviewer) or reviewer.agent_type == author.agent_type:
            reviews.append(ReviewResult(stage, REVIEW_VACANT))  # D5: nobody fills the billet; never the author
            continue
        status, answer = await _turn(
            reviewer, review_prompt(reviewer.callsign, author.callsign, body), min(clock() + turn_seconds, deadline),
        )
        outcome = parse_review(answer) if status == "answered" else REVIEW_NOT_REVIEWED
        reviews.append(ReviewResult(stage, outcome, reviewer.callsign, reviewer.agent_type, reviewer.did))

    envelope = {
        "version": AFTER_ACTION_VERSION,
        "timeline_id": timeline_id,
        "callsign": author.callsign,
        "agent_type": author.agent_type,
        "author_did": author.did,
        "flagged_at": flagged_at,
        "subject": subject,
        "source_episode_ids": list(cited),
        "review": [review.as_envelope() for review in reviews],
    }
    present = path_presence(records.repo_path / path)  # no await since: a report written meanwhile is kept
    if present is not False:
        return _done(AfterActionOutcome.ALREADY_WRITTEN, path, reviews) if present else _done(
            AfterActionOutcome.FAILED, "", reviews,
        )
    remaining = deadline - clock()
    if remaining <= 0:  # no write begins once the window has closed
        return _done(AfterActionOutcome.TIMED_OUT, "", reviews)
    written = records.write_entry(
        author=author.callsign,
        path=path,
        content=body,
        message=f"AD-1341 S5: after-action report of {author.callsign}",
        classification="ship",  # for every later crew, so ship-wide; C1 admits it to the archive
        status=AFTER_ACTION_STATUS,
        topic=f"After-action report of {author.callsign}",
        tags=["after-action", "ad-1341"],
        extra_frontmatter={AFTER_ACTION_KEY: envelope},
    )
    try:
        await asyncio.wait_for(written, timeout=remaining)
    except Exception as exc:  # log-and-degrade: what a cut-off write published stays and is reported (S4 A4)
        logger.warning("AD-1341 S5: %s's report write did not complete", author.callsign, exc_info=True)
        left = "" if path_presence(records.repo_path / path) is False else path
        outcome = AfterActionOutcome.TIMED_OUT if isinstance(exc, TimeoutError) else AfterActionOutcome.FAILED
        return _done(outcome, left, reviews)
    report = _done(AfterActionOutcome.WRITTEN, path, reviews)
    logger.info(
        "AD-1341 S5: after-action report of %s written at %s (%s)", author.callsign, path,
        "endorsed by the chain of command" if report.endorsed else "not endorsed: never archived",
    )
    return report


async def after_action_vessel(
    runtime: Any, callsign: str, subject: str, *, now: Callable[[], float] = time.time,
) -> AfterActionReport:
    """The Captain's ``/after-action`` on this vessel: refuse, or run one report and its review (D2, D3, D5)."""
    if not runtime.config.archive.enabled:
        raise AfterActionRefused("The Ship's Archive is disabled (archive.enabled), so no report would be archived.")
    records = runtime.records_store
    if records is None:
        raise AfterActionRefused("Ship's Records is not running, so no report could be kept.")
    ontology = runtime.ontology
    timeline_id = ontology.get_vessel_identity().instance_id if ontology is not None else ""
    if not timeline_id or timeline_id == "unknown":  # the ontology's placeholder when no identity is loaded
        raise AfterActionRefused("This vessel has no instance id, so a report could not be attributed to a timeline.")
    crew = crew_for_stand_down(runtime)
    wanted = callsign.strip().casefold()
    author = next((member for member in crew if member.callsign and member.callsign.casefold() == wanted), None)
    if author is None:
        raise AfterActionRefused("No crew agent answers to that callsign.")
    bus, memory = runtime.intent_bus, runtime.episodic_memory

    async def _ask(member: CrewMember, text: str) -> str | None:
        intent = IntentMessage(
            intent="direct_message",
            params={"text": text, "from": "captain", "session": False, BOUNDED_TURN_PARAM: True},  # S4 A2 (M2-1)
            target_agent_id=member.agent_id,
            ttl_seconds=AFTER_ACTION_TURN_SECONDS,
        )
        result = await bus.send(intent)
        if result is None or not result.success:  # refused, stopped or failed: no turn
            return None
        return DmReply.from_intent_result(result).body

    async def _recall(member: CrewMember) -> Sequence[Any]:
        if memory is None or not member.sovereign_id:
            return ()
        return await memory.recent_for_agent(member.sovereign_id, k=STAND_DOWN_EPISODES)

    return await run_after_action(
        author,
        subject=subject.strip(),
        flagged_at=time.strftime("%Y%m%dT%H%M%SZ", time.gmtime(now())),
        # D5 (Amendment A3): a fresh crew, with its identities, for each stage, so a billet filled or refilled meanwhile counts
        reviewers=lambda: chain_of_command_reviewers(author, crew_for_stand_down(runtime), ontology),
        ask=_ask,
        recall=_recall,
        records=records,
        timeline_id=timeline_id,
    )
```

```python
#: AD-1341 S5 (D9, Amendment A3): one UTC day in seconds. POSIX time counts no leap seconds, so every day is this long.
_DAY_SECONDS = 86_400.0

#: AD-1341 S5 (D9, Amendment A4, round 2's C2-1): how long after its UTC day ends a Captain's log still waits. One
#: writer call reads the clock for the day and again for the entry, so a call that stalls across midnight writes a
#: later entry into the earlier day's file. An hour covers every stall the vessel runs through; a longer one (a
#: suspended machine, a hung disk) shortens that entry's window by the excess (register R22).
_CAPTAINS_LOG_GRACE_SECONDS = 3_600.0

#: AD-1341 S5 (Amendment A4, round 2's C2-2): the plan record's mark for a Captain's log whose stored ``updated`` is
#: present but archives as no value (``_unreadable_update``).
_UPDATE_UNREADABLE = "record_updated_unreadable"


def _unreadable_update(kind: SourceKind, frontmatter: dict[str, Any]) -> dict[str, bool]:
    """AD-1341 S5 (Amendment A4, round 2's C2-2): the mark for a Captain's log whose ``updated`` is present but no text.

    ``_stored_text`` archives null, false, a container or an empty string as no value, as it does a missing field, so
    without the mark ``is_settled`` would read such a log as its writer's unstamped form and settle it by its day. A
    missing ``updated`` is not marked. Only a Captain's log is marked: every other kind already waits on an empty
    ``record_updated`` (it does not parse), so its record is unchanged.
    """
    if kind is SourceKind.CAPTAINS_LOG and "updated" in frontmatter and not _stored_text(frontmatter["updated"]):
        return {_UPDATE_UNREADABLE: True}
    return {}


def _captains_log_day_end(ref: str) -> float | None:
    """The end of a Captain's log file's UTC day (seconds since the epoch), or None for a name its writer never gives.

    ``RecordsStore.append_captains_log`` appends to ``captains-log/YYYY-MM-DD.md``. It reads the UTC clock for the day
    at the start of one synchronous call, again for the entry's time, and then writes. So a call that begins after the
    day has ended never writes to that day's file, but one that begins before midnight and stalls can (Amendment A4,
    round 2's C2-1: ``_CAPTAINS_LOG_GRACE_SECONDS``). It stamps ``created`` and never ``updated``.
    """
    try:
        day = date.fromisoformat(ref.removeprefix("captains-log/").removesuffix(".md"))
    except ValueError:
        return None
    if ref != f"captains-log/{day.isoformat()}.md":
        return None  # the writer's own name only: date.fromisoformat also reads 20261026 and 2026-W44-1
    return datetime.fromisoformat(f"{day.isoformat()}T00:00:00+00:00").timestamp() + _DAY_SECONDS


def is_settled(record: PromotionRecord, settled_before: float) -> bool:
    """AD-1341 S5 (D9): whether a source was last updated at or before ``settled_before`` (seconds since the epoch).

    Read from the record's ``record_updated`` (Ship's Records' ``updated``, an ISO 8601 time with its offset). A time
    with no offset, or one that does not parse, is not settled: such a source waits for the reset's promotion.

    Amendment A3: a Captain's log carries no ``updated`` (its writer stamps none), so it settles once its UTC day has
    ended and, if it carries an ``updated``, once that has settled too. Amendment A4 (round 2): the day's end counts
    only ``_CAPTAINS_LOG_GRACE_SECONDS`` later, because one writer call can stall across midnight (C2-1). Only a
    missing ``updated`` takes the day rule alone; one present but not text (``_UPDATE_UNREADABLE``) never settles here
    (C2-2). A Captain's log under another Markdown name (a compact or ISO-week date, a nested path) never settles here,
    and the reset still promotes it; a file that is not Markdown is no Ship's Records source on either path (C2-3).
    """
    if record.source_kind is SourceKind.CAPTAINS_LOG:
        ended = _captains_log_day_end(record.source_ref)
        if ended is None or ended + _CAPTAINS_LOG_GRACE_SECONDS > settled_before:
            return False
        if record.metadata.get(_UPDATE_UNREADABLE) is True:
            return False  # Amendment A4 (C2-2): a stored updated that is not a time is not a missing one
        if not record.metadata.get("record_updated"):
            return True  # the writer's own form: its day and the hour's grace have passed
    stamp = record.metadata.get("record_updated")
    if type(stamp) is not str:
        return False
    try:
        updated = datetime.fromisoformat(stamp)
    except ValueError:
        return False
    if updated.tzinfo is None:
        return False
    return updated.timestamp() <= settled_before


async def promote_settled(
    records: RecordsStore,
    archive: ArchiveStore,
    *,
    timeline_id: str,
    settled_before: float,
    max_created: int,
    cited_live: Callable[[tuple[str, ...]], Awaitable[bool]],
    exclusive: Callable[[], AbstractAsyncContextManager[Any]],
) -> PromotionReport:
    """AD-1341 S5 (D8 to D13): one continuous promotion. Archive settled sources, at most ``max_created`` new entries.

    The reset's own plan and rules (``plan_promotion``), so nothing reaches the archive here that the reset would not.
    A source is promoted only once it has settled (``is_settled``), so the Captain's review (``probos archive pending``,
    ``probos archive veto``) keeps a window before canon. A source the archive would not take now (present, erased,
    vetoed: ``source_state``) is passed over without a write. A source that cites episodes is promoted inside
    ``exclusive()`` (the AD-754 erasure lock) and only when ``cited_live`` says every cited episode is live, so no
    erasure runs between that check and the insert, nor between an erasure's own citation check and its erase (S3
    register R3). Anything else waits (``waiting``) for a later step or the reset; sources after the batch is full are
    not considered this time. No model call. Each write is ``promote_entry``'s one statement, so a step cut off part-way
    leaves only whole entries and the next step finds them present. Any failure propagates: the dream step logs it.
    """
    if type(max_created) is not int or max_created < 1:
        raise ValueError("AD-1341 S5: max_created is a positive integer")
    plan = await plan_promotion(records, timeline_id=timeline_id)
    created: list[str] = []
    present: list[str] = []
    erased: list[str] = []
    vetoed: list[str] = []
    waiting: list[str] = []
    by_outcome = {
        PromotionOutcome.CREATED: created,
        PromotionOutcome.PRESENT: present,
        PromotionOutcome.ERASED: erased,
        PromotionOutcome.VETOED: vetoed,
    }
    for record in plan.records:
        if len(created) >= max_created:
            break  # D10: the batch is full; the rest are considered by the next step
        if not is_settled(record, settled_before):
            waiting.append(record.source_ref)
            continue
        state = (await archive.source_state(record)).outcome
        if state is not PromotionOutcome.CREATED:
            by_outcome[state].append(record.source_ref)  # D10: no write for what the archive would not take
            continue
        if not record.source_episode_ids:
            by_outcome[await archive.promote_entry(record)].append(record.source_ref)
            continue
        async with exclusive():  # D11 (S3 R3): no erasure between the check below and the insert
            if not await cited_live(record.source_episode_ids):
                waiting.append(record.source_ref)  # a cited episode is not live: erased, demoted, or unreadable
                continue
            outcome = await archive.promote_entry(record)
        by_outcome[outcome].append(record.source_ref)
    logger.info(
        "AD-1341 S5: continuous promotion for timeline %s: %d created, %d already archived, %d erased by the Captain, "
        "%d vetoed by the Captain, %d waiting, %d withheld",
        timeline_id, len(created), len(present), len(erased), len(vetoed), len(waiting), len(plan.withheld),
    )
    return PromotionReport(
        created=tuple(created), present=tuple(present), erased=tuple(erased), withheld=plan.withheld,
        vetoed=tuple(vetoed), waiting=tuple(waiting),
    )
```

```python
"""AD-1341 S5 (#1569): continuous promotion into the Ship's Archive, a dream step behind a default-off flag.

With ``archive_promotion.enabled`` (off by default), each full dream cycle runs ``promote_settled`` once: Ship's
Records sources that meet the reset's own criteria and were last updated at least ``settle_hours`` earlier are
archived, at most ``max_per_cycle`` new entries a cycle. A source that cites episodes is archived only inside the
AD-754 erasure lock (``exclusive_with_erasure``) and only while every cited episode is live. No model call. With the
flag off nothing is wired, and the archive is written only by ``probos reset``, as before.
"""

from __future__ import annotations

import logging
import time
from collections.abc import Awaitable, Callable
from typing import Any

from probos.knowledge.archive_promotion import PromotionReport, promote_settled
from probos.knowledge.erasure import exclusive_with_erasure

logger = logging.getLogger(__name__)

Step = Callable[[], Awaitable[PromotionReport | None]]


def continuous_promotion_step(
    *,
    records: Callable[[], Any],
    archive: Callable[[], Any],
    memory: Callable[[], Any],
    timeline_id: Callable[[], str],
    settle_seconds: float,
    max_created: int,
    clock: Callable[[], float] = time.time,
) -> Step:
    """The dream step: each call promotes once (D8 to D11), or returns None when it cannot run now.

    The stores are read at each call, so a store closed at shutdown or failed at boot is simply absent: no step runs.
    A vessel without an instance id promotes nothing (its entries could not be attributed).
    """

    async def step() -> PromotionReport | None:
        store, documents, episodes, timeline = archive(), records(), memory(), timeline_id()
        if store is None or documents is None:
            return None  # the archive is closed, disabled or failed at boot, or Ship's Records is not running
        if type(timeline) is not str or not timeline.strip() or timeline == "unknown":
            logger.warning("AD-1341 S5: this vessel has no instance id; nothing is promoted continuously")
            return None

        async def cited_live(ids: tuple[str, ...]) -> bool:
            if episodes is None:
                return False  # the citations cannot be checked, so the lesson waits for the reset
            found = await episodes.get_by_ids(list(ids))
            return {getattr(episode, "id", None) for episode in found} >= set(ids)

        return await promote_settled(
            documents,
            store,
            timeline_id=timeline,
            settled_before=clock() - settle_seconds,
            max_created=max_created,
            cited_live=cited_live,
            exclusive=lambda: exclusive_with_erasure(episodes),
        )

    return step


def vessel_timeline(runtime: Any) -> str:

    ontology = getattr(runtime, "ontology", None)
    return ontology.get_vessel_identity().instance_id if ontology is not None else ""


def wire_continuous_promotion(runtime: Any, engine: Any) -> bool:
    """AD-1341 S5 (D8): give ``engine`` the step when the Captain enabled it; True when wired.

    Checked by identity (``is True``), so a test double's attribute wires nothing. The Ship's Archive must be enabled
    too: a disabled archive promotes nothing at the reset either.
    """

    if getattr(section, "enabled", False) is not True:

        return False
    engine.set_continuous_promotion(continuous_promotion_step(
        records=lambda: runtime.records_store,
        archive=lambda: runtime.archive_store,
        memory=lambda: getattr(runtime, "episodic_memory", None),
        timeline_id=lambda: vessel_timeline(runtime),
        settle_seconds=section.settle_hours * 3600.0,
        max_created=section.max_per_cycle,
    ))

        "AD-1341 S5: continuous promotion wired (settle %.1f h, at most %d entries a dream cycle)",
        section.settle_hours, section.max_per_cycle,
```
