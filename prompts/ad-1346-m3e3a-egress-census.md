## 2. Solution

- **The effect.** `EFFECT_EGRESS: Final = "egress"` in `taxonomy.py`, appended last to `TICKET_EFFECTS`. `TICKET_OPERATIONS` becomes `("issue", "tool", "model_call", "subprocess", "egress")`. `ticket_findings`' per-day bound becomes 5 × 12 × 13 × 2 = 1,560 rows, 54,600 over 35 days. The scope a hold asks for (`service.py:55`) includes it.
- **The scan.** `egress_points()` in the fixture parses every `src` module and records each call whose callee is a name of `EGRESS_PRIMITIVES`, as the module's absolute imports bind it, by (file, enclosing scope). A call whose callee is not such a name is recorded once for each argument, positional or keyword, that is one. A name that no absolute import in the module binds is not resolved.
- **The census.** `EGRESS_SITES` holds one row per (file, scope) with its count and one coverage:
  - `Pending("M3e3b", ...)`: 5 rows;
  - `OtherClass("model_call", ...)`: 1 row;
  - `System(SHIP, ...)`: 28 points in 27 rows;
  - `ReachedOnlyFrom(...)`: 2 rows;
  - `OutsideRuntime(...)`: 7 points in 5 rows;
  - 43 points in 40 rows in all.
- **The guard.** EN1 fails on an unlisted point, a stale row or a changed count. EN7 fails when `src` imports a top-level module, other than `probos`, `__future__` and the names in `sys.stdlib_module_names`, that is neither the first component of a name of `EGRESS_PRIMITIVES` nor a member of `IMPORTS_WITHOUT_PRIMITIVE`, or when a member is not imported or is the first component of a name of `EGRESS_PRIMITIVES` (D201).
- **No sink.** No `check_at` is added and nothing is refused. Property 12 is not advanced in this slice.

## 3. Decisions (numbered after M3e2b's D185 to D193)

- **D194 The egress point and its scan** (question 1). An egress point is a call whose callee is an `EGRESS_PRIMITIVES` name (a constructor or a one-shot call of a network library), as the module's absolute imports bind it; a call whose callee is not such a name holds one point for each argument, positional or keyword, that is one.
  - **How it is counted.** By BF-892's scope convention: class and function names joined by `.`, a lambda taking its enclosing function's scope, `<module>` at module level. Every module is parsed, with no text prefilter (M3e2a's F1).
  - **Where it lives.** In the fixture, beside the subprocess census's helpers.
  - **The guard.** EN1 compares the found counts with the rows exactly. EN6 pins three shapes the scan must reach.
  - **Ranked:**
    1. this (correct for every call the 42-match pattern finds, without its 16 non-points; it finds 17 the pattern misses; it changes no `src` code);
    2. the text pattern as the census;
    3. the `EgressPolicy` consult sites (three consumers, §1);
    4. a `sys.addaudithook` observer of `socket.connect` (it counts only the paths a run exercises, so it is not a census; D165 rejected it; considered for M3e5 evidence, not done here).
  - **Rejected: reusing BF-892's `_file_aliases`.** It resolves a name that no import binds to itself (`aliases.get(node.id, (node.id,))`, `tests/test_bf892_spawn_env_guard.py:179`), so a store named `requests` would resolve to `requests.get`.
  - **The request call** (`client.post`, `.get`) is not the point. Its receiver is held elsewhere and `dict.get` shares its name. M3e3b places each sink at the request function, not at the construction (register R92).
- **D195 The classification** (question 2).
  - A point is `Pending("M3e3b")` when agent or model text picks its destination or its content, as that agent's work:
    - `http_fetch`'s URL;

def _import_aliases(tree: ast.Module) -> dict[str, frozenset[str]]:
    """AD-1346 M3e3a: the dotted names each name is bound to by the module's absolute imports, in any scope."""
    names: dict[str, set[str]] = {}
    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            for alias in node.names:
                bound = alias.asname or alias.name.split(".")[0]
                names.setdefault(bound, set()).add(alias.name if alias.asname else bound)
        elif isinstance(node, ast.ImportFrom) and node.level == 0 and node.module:
            for alias in node.names:
                names.setdefault(alias.asname or alias.name, set()).add(f"{node.module}.{alias.name}")
    return {name: frozenset(targets) for name, targets in names.items()}


def _primitive(node: ast.AST, aliases: dict[str, frozenset[str]]) -> str | None:
    """The first name of ``EGRESS_PRIMITIVES``, in sorted order, that ``node`` may denote, or None."""
    parts: list[str] = []
    while isinstance(node, ast.Attribute):
        parts.append(node.attr)
        node = node.value
    heads = aliases.get(node.id, frozenset()) if isinstance(node, ast.Name) else frozenset()
    tail = "".join(f".{part}" for part in reversed(parts))
    matches = sorted(head + tail for head in heads if head + tail in EGRESS_PRIMITIVES)
    return matches[0] if matches else None


class _EgressScan(ast.NodeVisitor):
    def __init__(self, aliases: dict[str, frozenset[str]]) -> None:
        self.aliases = aliases
        self.scope: list[str] = []
        self.points: list[tuple[str, int, str, str]] = []

    def _enter(self, node: ast.ClassDef | ast.FunctionDef | ast.AsyncFunctionDef) -> None:
        self.scope.append(node.name)
        self.generic_visit(node)
        self.scope.pop()

    visit_ClassDef = visit_FunctionDef = visit_AsyncFunctionDef = _enter

    def visit_Call(self, node: ast.Call) -> None:
        where = ".".join(self.scope) or "<module>"
        callee = _primitive(node.func, self.aliases)
        if callee is not None:
            self.points.append((where, node.lineno, callee, "direct"))
        else:
            for arg in [*node.args, *(keyword.value for keyword in node.keywords)]:
                passed = _primitive(arg, self.aliases)
                if passed is not None:
                    self.points.append((where, node.lineno, passed, "by-reference"))
        self.generic_visit(node)
