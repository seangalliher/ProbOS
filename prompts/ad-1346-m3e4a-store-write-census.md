## 1. Problem

- `EFFECT_CLASSES["store_write"]` is `"AD-1346 M3e4"` (`tests/fixtures/ad1346_effect_census.py:66`), and `DELIVERED` holds four classes (`:69`). `TICKET_EFFECTS` holds four effects (`admission/tickets.py:64`). EC7 asserts `DELIVERED < frozenset(EFFECT_CLASSES)` (`tests/test_ad1346_admission_effect_census.py:295`).
- `src` holds no census of store writes. By `rg` (§11), quoted SQL write strings appear 460 times in 80 files, upper case. Among them are the Ward Room (`ward_room/messages.py`, `threads.py`, `channels.py`) and the episodic memory (`cognitive/episodic.py`), alongside the stores of the admission service (`admission/store.py`) and the stop service (`agent_stop.py`).
- The existing inventories count other things:
  - `scripts/check_store_registry.py` detects modules that build a `CREATE TABLE` (`:15-20`), which records schema rather than writes.
  - `scripts/check_architecture_principles.py`'s `db-connect` counts calls rendered `sqlite3.connect` or `aiosqlite.connect` (`:191-193`), which records connections rather than writes.
- The three store kinds that M3e1's D160 line named (episodes, Ward Room and DM posts, notebooks) sit in different primitive families:
  - Ward Room posts and threads are SQL. `WardRoomService.create_post` (`ward_room/service.py:466-471`) and `create_thread` (`:413-420`) call `MessageStore` and `ThreadManager`. A DM is a post in a channel of type `dm` (`:286`).
  - Episodes are ChromaDB and SQL. `EpisodicMemory.store` is at `cognitive/episodic.py:1991`; `_collection.add` is at `:2195` and `executemany("DELETE FROM episode_fts ...")` at `:1809`.
  - Notebooks are files: `RecordsStore.write_notebook` (`knowledge/records_store.py:490`) calls `write_entry` (`:531`), and `records_store.py` holds no SQL write string.
- Hidden pins this slice meets:
  - K1 pins `TICKET_EFFECTS` and `TICKET_OPERATIONS` (`tests/test_ad1346_admission_tickets.py:145-146`).
  - EC1 pins them and the per-day bound of 1,560 (`tests/test_ad1346_admission_effect_census.py:201-206`).
  - TR6 recomputes that bound against `AGGREGATE_ROW_LIMIT` (`tests/test_ad1346_admission_ticket_record.py:281-282`).

## 2. Solution

- **The effect.** `EFFECT_STORE_WRITE = "store_write"` is appended to `TICKET_EFFECTS`, so `TICKET_OPERATIONS` gains it. The scope `hold` asks for (`service.py:59`) then includes it, and `DELIVERED` gains `"store_write"`. `ticket_findings`' per-day bound becomes 6 × 12 × 13 × 2 = 1,872 rows, or 65,520 over 35 days, below `AGGREGATE_ROW_LIMIT` (100,000, `admission/store.py:89`).
- **The census.** A new fixture, `tests/fixtures/ad1346_store_census.py`:
  - `sql_write_scan` reports the SQL write statements of a module (D219).
  - `STORE_WRITE_FILES` gives each `src` file holding one a coverage: 3 `Pending("M3e4b", ...)`, 28 `Pending("M3e4c", ...)`, 47 `System`, 1 `OutsideRuntime`. That is 79 rows.
- **No check is added.** No `check_at` call is added, and nothing is refused or charged.

## 3. Decisions (numbered after M3e3c's D210 to D216)

- **D217 The cut** (question 9). Covered: the effect and the SQL census, with no check. Next, in order: M3e4b (register R110), then M3e4c (R111, R112), then M3e4d (R113), then M3e5.

  - A write about an agent, made by one of the ship's services, is a `System` row.
  - So is a copy that one of the ship's services makes of content an agent produced, with or without the author's id. A check belongs at the agent's own write, not at the copy. Three rows hold such copies:
    - `cognitive/episode_archive.py`: `EpisodeArchive.archive` is called from `EpisodicMemory._archive_records` as episodes leave live memory, including in the eviction that `EpisodicMemory.store` can run;
    - `knowledge/archive_store.py`: `ArchiveStore.promote_entry` is called from `knowledge/archive_promotion.py`, which `probos reset` (`__main__.py`) and the dream cycle (`knowledge/continuous_promotion.py`) import;

  - Ranked:
    1. this;
    2. every write inside a held unit of work (a dynamic property that a static census cannot classify; it would count bookkeeping writes as the agent's);
    3. every store an agent's code path can reach;
    4. only the three stores M3e1 named (no rule for the next store);
    5. a copy that keeps the author's id counts as the author's (the check would fall on the ship's retention and promotion, not on the agent's write).
- **D219 The vocabulary and the primitive** (question 1).
  - `EFFECT_STORE_WRITE` is appended, as M3e3a appended `EFFECT_EGRESS` (D196), and `DELIVERED` gains `"store_write"`. EC7's strict subset becomes equality.
  - A point is a string node that is not a docstring: a `str` constant, or an f-string with each placeholder read as `_`. It counts when `SQL_WRITE` matches the node's text at its start after leading whitespace, with one of these starts: `INSERT INTO`, `INSERT OR <WORD> INTO`, `REPLACE INTO`, `UPDATE <name> SET`, `DELETE FROM`, in upper case.
  - The match is anchored to the start because a search anywhere in the text matches prose, such as `"No DELETE FROM in probos.acm. ..."` (`src/probos/storage_declarations.py:220`).
  - Ranked:
    1. this (finds a statement held in a variable before `execute`; skips docstrings; reads `f"UPDATE {table} SET ..."`, `ward_room/messages.py:611`);
    2. calls of `execute`, `executemany` or `executescript` with a literal first argument (misses SQL held in a variable; `execute` also names non-SQL methods);
    3. a text grep (no docstring or f-string handling; D194 chose AST for egress on the same ground);
    4. the store registry's `CREATE TABLE` modules (schema, not writes).

def _docstrings(tree: ast.Module) -> set[int]:
    """The ids of the docstring constants of the module and of each class and function in it."""
    found: set[int] = set()
    for node in ast.walk(tree):
        if isinstance(node, (ast.Module, ast.ClassDef, ast.FunctionDef, ast.AsyncFunctionDef)) and node.body:
            first = node.body[0]
            if isinstance(first, ast.Expr) and isinstance(first.value, ast.Constant) and isinstance(first.value.value, str):
                found.add(id(first.value))
    return found


class _SqlWriteScan(ast.NodeVisitor):
    def __init__(self, docstrings: set[int]) -> None:
        self.docstrings = docstrings
        self.scope: list[str] = []
        self.points: list[tuple[str, int]] = []

    def _enter(self, node: ast.ClassDef | ast.FunctionDef | ast.AsyncFunctionDef) -> None:
        self.scope.append(node.name)
        self.generic_visit(node)
        self.scope.pop()

    visit_ClassDef = visit_FunctionDef = visit_AsyncFunctionDef = _enter

    def _point(self, node: ast.expr, text: str) -> None:
        if SQL_WRITE.match(text):
            self.points.append((".".join(self.scope) or "<module>", node.lineno))

    def visit_Constant(self, node: ast.Constant) -> None:
        if isinstance(node.value, str) and id(node) not in self.docstrings:
            self._point(node, node.value)

    def visit_JoinedStr(self, node: ast.JoinedStr) -> None:
        # The placeholders are not visited: a string inside one is not a point.
        self._point(node, "".join(part.value if isinstance(part, ast.Constant) else "_" for part in node.values))
