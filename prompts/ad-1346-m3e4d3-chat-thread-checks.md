## 2. Solution

- **The checks (D299).**
  - `create_thread` calls `check_at(self._admission, effect=EFFECT_STORE_WRITE, presented_id=meta.get("created_by_agent"))` as the statement before its `with self._connect() as conn:`.
  - `append_message_once` calls it with `presented_id=author_id` as the statement before its `with self._connect() as conn:`.
  - Each imports `check_at` and `EFFECT_STORE_WRITE` inside the method.
- **The hand-off (D300).** `ChatThreadStore` gains a class-level `_admission: object = None` and an instance `set_admission`. `ProbOSRuntime.start` hands it `self.admission_service` (or None) under `isinstance`, after the persistent task store's hand-off.
- **The rows (D298).** `threads/__init__.py` leaves `STORE_WRITE_FILES` and `AGENT_ATTRIBUTED_SCOPES` and is split by scope in `STORE_WRITE_SCOPES`: 2 `StoreCheck` rows and 22 `System` rows.
  - `STORE_WRITE_SCOPES` then holds 11 checks and 40 `System` rows in 7 files (hand).
  - `STORE_WRITE_FILES` holds 72 rows: 5 pending, 66 the ship's, 1 the command line's (hand).
- **Shadow only.** `check_at` does nothing unless it is handed an exact `AdmissionService` (`admission/seam.py:55-59`). Nothing is refused, charged or answered differently (WM11).

async def _chat_round(store: ChatThreadStore, phase: int) -> list[object]:
    """AD-1346 M3e4d3: one round of three checked writes: a thread ``AGENT_A`` creates, a message by ``AGENT_B``, and a
    message by ``AGENT_A`` appended through ``asyncio.to_thread``. Returns each answer without the fields a fresh store
    draws."""

        title=f"ad1346 m3e4d3 golf {phase}", participants=[AGENT_A, AGENT_B], metadata={"created_by_agent": AGENT_A},
    )

        store.append_message, thread.id, author_id=AGENT_A, role="agent", body=f"ad1346 m3e4d3 india {phase}",
