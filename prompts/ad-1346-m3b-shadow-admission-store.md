## 1. Problem

- The shadow decision of M3a keeps its counts only in memory: `AdmissionService._tally`, `_latency` and `_failures` (`src/probos/admission/service.py:47-49`). A restart loses them. #1601's evidence 2 (at least 50 decisions per live work kind), 7 (persisted p99) and 8 (a service-written record, with producer against consumer markers counted on the live vessel) all need a durable store. The memo puts it in M3b (#1604 comment 6306056229: D9 a dedicated store, D10 bounded from day one).
- The service docstring says "AD-1346 M3b persists the counts" (`service.py:9`). No store, recorder or report exists (Absence Verified).
- Hidden pins a new store and a new shutdown step must meet (#1604 memo, "Hidden pins"):
  - the store registry's module discovery and baseline (`scripts/check_store_registry.py:44-47`, `:1064-1071`);
  - the failed-start rollback census (`tests/test_issue1419_failed_start_rollback.py:1127-1177`, `:1393-1397`, `:1890-1899`);
  - T14's per-file import allowlist, whose first check is that the package's files are exactly the allowlist's keys (`tests/test_ad1346_admission_service.py:457`);

## 2. Solution

- **`probos.admission.store.AdmissionShadowStore`** opens `admission_shadow.db` in the runtime's data directory through an injected `ConnectionFactory`. The file holds one `schema_version` row and three bounded tables: aggregates per (UTC day, work kind, seam, outcome, reason code, latency bucket), a ring of would-refuse samples, and markers per (boot, UTC hour). Its methods are `start`, `stop`, `write_batch(boot_id, batch)` (one transaction) and `prune(now)` (one transaction).
- **`probos.admission.recorder.ShadowRecorder`**:
  - `offer(verdict, elapsed_ns)` is synchronous: it counts in memory and returns.
  - One owned flusher task writes what is pending every 5 s, and prunes at the first flush of each UTC day and at each later flush that day until a prune succeeds.
  - `stop()` waits for the flusher's last flush without cancelling it, then flushes what is still pending, at most twice.
  - Markers: `offered` is the producer marker; `written` is the consumer marker; `dropped` and `samples_dropped` count what the bounds kept out.
- **`AdmissionService(..., recorder=None)`**: `shadow` offers each verdict it counted, with its measured time. `decide` is unchanged.
- **The runtime** starts the store and the recorder before the service. On an `Exception` it logs one warning, builds the service with no recorder, and the boot continues. **Shutdown** stops the recorder, then the store, before the identity registry.
- **`probos.admission.report`** holds six read-only queries by frozen name, `open_read_only` (`mode=ro`) and `p99_bucket`.

## 3. Decisions (numbered after M3a's D1 to D37)

- **D38 The store: file, place, opening.** `admission_shadow.db` (`STORE_FILENAME`) in `ProbOSRuntime._data_dir` (assigned in `ProbOSRuntime.__init__`). The class is `AdmissionShadowStore(*, data_dir, connection_factory=None)`; it falls back to `probos.storage.sqlite_factory.default_factory` and runs WAL, `busy_timeout=5000` and `synchronous=NORMAL`. This is the shape of `AgentStopService` (`agent_stop.py:331-374`) and `ActionApprovalStore` (`tools/action_approvals.py:126-149`). The connection is held directly as `_db`, so BF-882's last-resort close can reach it (`shutdown.py:600-609`). Reason: D9 (memo) puts the record in a dedicated store, and the standard shape keeps the last-resort close working.
- **D39 `schema_version`.** The table is `schema_version(version INTEGER NOT NULL)`. A file with no row gets `SCHEMA_VERSION = 1` after the tables are created. A file with exactly one row equal to 1 is opened. Any other rows raise `RuntimeError` before anything is written to the file, and `start` closes the connection it opened. There is no migration: version 1 is the first layout. Reason: a refusal is safer than mixing an unknown layout with this one, and the runtime fails open around it (D47).
- **D40 Tables and columns.**
  - `shadow_aggregates(day, work_kind, seam, outcome, reason_code, latency_bucket, decisions)`, primary key the first six. Counts are added by upsert.
  - `shadow_samples(seq INTEGER PRIMARY KEY AUTOINCREMENT, boot_id, hour, recorded_at, work_kind, seam, outcome, reason_code, latency_ns, verdict_json)`.
  - `shadow_markers(boot_id, hour, offered, written, dropped, samples_dropped)`, primary key `(boot_id, hour)`, counts added by upsert.
  - `day` is `YYYY-MM-DD` and `hour` is `YYYY-MM-DDTHH`, both UTC of the recorder's wall clock (`time.time` unless injected). The latency bucket is M3a's: `min(ns.bit_length(), 39)` (`AdmissionService._count`).
  - Reason: a persisted p99 per work kind with no read-modify-write, and a per-boot producer/consumer comparison.
- **D41 Bounds (D10) and what happens at each bound.** These are module constants of `store.py`:
  - `AGGREGATE_RETENTION_DAYS = 35`: `prune(now)` deletes aggregate days before the current UTC day minus 34.
  - `AGGREGATE_ROW_LIMIT = 100_000`: while more rows remain, `prune` deletes the oldest whole day, but never the current day.
  - `SAMPLE_RING_SIZE = 5_000`: each `write_batch` that adds samples keeps only the newest 5,000.
  - `MARKER_RETENTION_DAYS = 35`: the same day rule for markers.
  - `MARKER_ROW_LIMIT = 50_000`: beyond it, `prune` deletes the oldest hours.

  With M3a's vocabularies (11 work kinds × 12 seams × 4 reason codes × 40 buckets), one day holds at most 21,120 aggregate rows; S9 pins that this product stays below the row limit. Reason: the F-209 lesson (bounded from day one); whole days keep each reported day complete.
- **D42 Samples.** Only verdicts whose outcome is not `admit`, stored as `json.dumps(verdict.to_dict(), separators=(",", ":"))`, so the keys are in `VERDICT_KEYS` order. Reason: the memo's ring is "non-admit or disagreement". Disagreement needs M3c's `today_outcome`, so M3b samples only would-refuse verdicts.
- **D43 Markers, and what they count in M3b alone.**
  - `offered` (the producer marker) is counted by `offer` for each verdict offered before `stop` began.
  - `written` (the consumer marker) is the number of verdicts a committed `write_batch` added to the aggregates for that hour.
  - `dropped` counts verdicts not counted because of `PENDING_KEY_LIMIT`; `samples_dropped` counts samples not kept because of `SAMPLE_BUFFER_LIMIT`.
  - All four reach the store in the same transaction as the counts they describe. After a clean stop whose last write succeeded, each row holds `offered == written + dropped`.
  - `boot_id` is a fresh `uuid4().hex` per recorder. `start` marks its hour, so each boot's first successful write adds a row even when nothing was offered.
  - **In M3b alone**, nothing in `src` calls `shadow` (Absence Verified), so on the vessel each boot whose recorder started and wrote to the store adds one marker row with zero counts, and the aggregates and samples stay empty.
- **D44 `offer`.** `offer(self, verdict: AdmissionVerdict, elapsed_ns: int) -> None`. It is synchronous, awaits nothing and makes no I/O, store, task or wait call (R2 pins it by AST). Once `stop` has begun it counts `late` (memory only) and returns. A verdict needing a new pending key when `PENDING_KEY_LIMIT = 50_000` keys are pending is counted as `dropped` and neither aggregated nor sampled. A would-refuse sample beyond `SAMPLE_BUFFER_LIMIT` (= `SAMPLE_RING_SIZE`) pending samples is counted as `samples_dropped`; the verdict itself is still counted. Reason: pending counts are bounded by the key space, not by call volume, and nothing blocks.
- **D45 The flusher: cadence, ownership, stop path.**
  - `FLUSH_INTERVAL_SECONDS = 5.0`, the same delay as OpenTelemetry's batch processor default (§13).
  - One task, `self._task = asyncio.create_task(self._run(), name=FLUSHER_TASK_NAME)` (`"ad1346-shadow-flusher"`), started by `start()`, which raises `RuntimeError` on a second call or after `stop` began.
  - Each flush first calls `prune(now)` when the UTC day differs from the last day a prune succeeded on.
  - A write that raises an `Exception` puts its batch back, keeping at most `SAMPLE_BUFFER_LIMIT` samples and counting the rest as `samples_dropped`. `flush_failures` increments; the first failure is logged at WARNING with its traceback and later ones at DEBUG. A `BaseException` that is not an `Exception` puts the batch back and propagates.
  - `stop()` sets `_stopping`, sets the stop event and awaits the task with `asyncio.wait`, without cancelling it, so this call never cuts a write. It then flushes while anything is pending, at most `STOP_FLUSH_ATTEMPTS = 2` times, and logs a WARNING naming what was not written.
  - **`unowned-task` row delta: 0.** The reference is assigned, not a bare `ast.Expr` (`check_architecture_principles.py:93-98`, `:652-677`).
- **D46 The service hook.** `AdmissionService.__init__` gains `recorder: ShadowRecorder | None = None`, keyword-only after `clock`; anything that is neither a `ShadowRecorder` nor None raises `TypeError`. Inside `shadow`'s `try`, after `_count`, it runs `if self._recorder is not None: self._recorder.offer(verdict, elapsed)`.
  - `decide` is unchanged: it still reads the stop only with `stop_for`, never `refusal()` or `active_stop()` (#1604 constraint; T15 pins it), and has no await, lock or I/O (T14).
  - **Reason codes and seams:** M3b adds none. It persists M3a's vocabulary, which imports S1's `SEAMS` and `STOP_REASON_CODE` (`taxonomy.py:15-16`) and shares the AD-1316 code syntax (D8: shared by syntax, not imported).
  - **Shadow never blocks and never charges:** `shadow` still returns None, and `offer` is O(1). D50 covers trust, budget and stop.
- **D47 Store failure: the service is built anyway.** In `ProbOSRuntime.start`, after the `self.identity_service = IdentityService(` assignment and before the service, one `try` holds the two imports, `AdmissionShadowStore(data_dir=self._data_dir)`, `await shadow_store.start()`, `ShadowRecorder(shadow_store)` and `recorder.start()`. Each attribute (`admission_shadow_store`, `admission_shadow_recorder`) is assigned only after its object started. On an `Exception`, `logger.warning("AD-1346 M3b: the shadow admission store or its recorder did not start; the service is built without a recorder", exc_info=True)`; the service is then built with `recorder=None` and the boot continues. The log call has no guard of its own, as in M3a (D36).
- **D48 Shutdown.** Two `with steps(...)` blocks run immediately before `# Stop Identity Registry (AD-441)`:
  - `"admission shadow recorder stop"`, then `"admission shadow store stop"`;
  - each is read with `getattr(runtime, ..., None)`, as `agent_stops` is (`shutdown.py:1471`), and set to None afterwards;
  - two `_STOPPED_COMPONENTS` rows, and the store joins `_BREAKABLE_BEFORE_CLEANUP`.

  The service keeps its reference to the stopped recorder until the identity block releases the service; a verdict offered in between counts as `late`. Rejected: one step (the reach of the last-resort close), and `_stop_runtime_sqlite_sidecars` (it sets no recorder-before-store order and is outside the census).
- **D49 The report's frozen query names.** `REPORT_QUERIES` is a `MappingProxyType` mapping each name to one SELECT. Names may be appended and are never renamed or removed:
  - `decisions_by_work_kind` (since day)
  - `latency_by_work_kind` (since day)
  - `would_refuse_samples` (limit)
  - `markers_by_boot`
  - `days_recorded`
  - `schema_version`

  `run_query(db, name, params=())` raises `ValueError` before using `db` when `name` is not an exact `str` held by the mapping. `open_read_only(path)` returns `default_factory.connect(str(path), read_only=True)` (BF-906 `mode=ro`). `p99_bucket(counts)` returns the first bucket whose running count reaches 99% of the total, or None for a total of zero or less. Reason: #1604's memo freezes these names for the Captain's evidence run at the M4 ruling.
- **D50 Shadow mutates no trust, budget or stop.** No file of the admission package imports a trust or budget module; T14's allowlists list every import. The stop record is read only through `stop_for`. B1 measures it on a real boot: across three `shadow` calls with no await between the reads, `trust_network.raw_scores()` and the Captain's stop's `refused_counts` are unchanged.
- **D51 The real-boot persistence test.** B1 boots twice on one `tmp_path` data directory, the way M3a's T17 boots (`tests/test_ad1346_admission_service_boot.py:42-53`: `SystemConfig()` with the naming ceremony, the proactive loop and QA off, and `MockLLMClient()`). It reads the file through the report after the second stop. B3 uses `make_runtime` with `lifecycle_config(..., zero_grace=True)`, as M3a's T18 does. No new test passes a data directory outside `tmp_path`, and neither the four new test files nor `tests/fixtures/ad1346_shadow.py` reads the environment (§15).
- **D52 The declaration (AD-1256).** Id `admission.shadow-decisions`, owner `probos.admission.store.AdmissionShadowStore`, `canonical_path="admission_shadow.db"`, `OPTIONAL`, `BOUNDED`, backup `included` (AD-1265's default for an unlisted file, `tests/test_ad1265_backup_coverage.py:159-162`), restore `unknown`. Lifecycle owner: `unowned` in M1 and M2, `probos.runtime.ProbOSRuntime.start` from M3.

```python
    """Ship's Computer store: the shadow admission decision's durable record (AD-1346 M3b)."""

    async def start(self) -> None:

        Raises ``RuntimeError`` when the store is already open or the file holds other

        after the connection opened, it closes that connection first (a close that raises is logged

                    f"version {SCHEMA_VERSION} and has no migration"

            await db.execute("PRAGMA busy_timeout=5000")
            await db.execute("PRAGMA synchronous=NORMAL")

            if not rows:
                await db.execute(_INSERT_VERSION, (SCHEMA_VERSION,))
            await db.commit()
        except BaseException:
            try:
                await db.close()
            except Exception:  # noqa: BLE001 -- the start's own exception is the one the caller needs
                logger.debug("AD-1346 M3b: closing the shadow store after a failed start raised", exc_info=True)
            raise
        self._db = db

        ``_db`` is cleared only after the close returns, so a startup rollback's last-resort close
        (BF-882) still finds a connection whose close raised.
        """
        if self._db is not None:
            await self._db.close()
            self._db = None

    def _connection(self) -> DatabaseConnection:
        if self._db is None:
            raise RuntimeError("AD-1346 M3b: the shadow admission store is not open")
        return self._db

    async def write_batch(self, boot_id: str, batch: ShadowBatch) -> int:
        """Write ``batch`` for ``boot_id`` in one transaction; the number of verdicts added to the aggregates.

        Each aggregate key's count is added to its row for that UTC day (the hour's first ten
        characters). Each sample becomes a row, and then the newest ``SAMPLE_RING_SIZE`` are kept.
        The marker row of each hour in the batch gains that hour's offered, dropped and
        samples-dropped counts, and the verdicts this call added to the aggregates for that hour. An
        exception from the statements or the commit rolls the transaction back and propagates.
        Raises ``RuntimeError`` when the store is not open.
        """
        db = self._connection()
        written: dict[str, int] = {}
        aggregates: list[tuple[str, str, str, str, str, int, int]] = []
        for (hour, work_kind, seam, outcome, reason_code, bucket), decisions in batch.aggregates.items():
            aggregates.append((hour[:10], work_kind, seam, outcome, reason_code, bucket, decisions))
            written[hour] = written.get(hour, 0) + decisions
        samples = [
            (
                boot_id, sample.hour, sample.recorded_at, sample.verdict.work_kind, sample.verdict.seam,
                sample.verdict.outcome, sample.verdict.reason_code, sample.latency_ns,
                json.dumps(sample.verdict.to_dict(), separators=(",", ":")),
            )
            for sample in batch.samples
        ]
        hours = sorted(set(batch.offered) | set(written) | set(batch.dropped) | set(batch.samples_dropped))
        markers = [
            (
                boot_id, hour, batch.offered.get(hour, 0), written.get(hour, 0), batch.dropped.get(hour, 0),
                batch.samples_dropped.get(hour, 0),
            )
            for hour in hours
        ]
        try:
            if aggregates:
                await db.executemany(_UPSERT_AGGREGATE, aggregates)
            if samples:
                await db.executemany(_INSERT_SAMPLE, samples)
                await db.execute(_TRIM_SAMPLES, (SAMPLE_RING_SIZE,))
            if markers:
                await db.executemany(_UPSERT_MARKER, markers)
            await db.commit()
        except BaseException:
            await _rollback_quietly(db)  # a later commit must not land part of this batch
            raise
        return sum(written.values())

    async def prune(self, now: float) -> tuple[int, int]:
        """Apply D10's bounds at wall-clock time ``now``, in one transaction; the aggregate and marker rows deleted.

        Raises ``RuntimeError`` when the store is not open; an exception from SQLite rolls the
        transaction back and propagates.
        """
        db = self._connection()
        today = utc_day(now)
        try:
            cursor = await db.execute(
                _PRUNE_AGGREGATES, (utc_day(now - (AGGREGATE_RETENTION_DAYS - 1) * DAY_SECONDS),),
            )
            aggregates = cursor.rowcount
            while True:
                async with db.execute(_COUNT_AGGREGATES) as cursor:
                    count, oldest = await cursor.fetchone()
                if count <= AGGREGATE_ROW_LIMIT or oldest >= today:
                    break
                cursor = await db.execute(_DELETE_AGGREGATE_DAY, (oldest,))
                aggregates += cursor.rowcount
            cursor = await db.execute(
                _PRUNE_MARKERS, (utc_day(now - (MARKER_RETENTION_DAYS - 1) * DAY_SECONDS),),
            )
            markers = cursor.rowcount
            async with db.execute(_COUNT_MARKERS) as cursor:
                (count,) = await cursor.fetchone()
            if count > MARKER_ROW_LIMIT:
                cursor = await db.execute(_DELETE_OLDEST_MARKERS, (count - MARKER_ROW_LIMIT,))
                markers += cursor.rowcount
            await db.commit()
        except BaseException:
            await _rollback_quietly(db)  # a later commit must not land part of this prune
            raise
        return aggregates, markers
```

### 7.9.N New file: `src/probos/admission/recorder.py` (M2)

```python
"""AD-1346 M3b (#1604): the shadow admission recorder, a synchronous ``offer`` and a write-behind flusher.

``AdmissionService.shadow``, in a service built with a recorder, hands it each verdict it counted
and the ``decide`` time it measured. ``offer`` adds them to in-memory counts and returns: it awaits
nothing and does no I/O. The flusher, an asyncio task this object holds from ``start`` until
``stop`` has awaited it, hands those counts to ``AdmissionShadowStore.write_batch`` every
``FLUSH_INTERVAL_SECONDS``. It calls ``prune`` at the first flush of each UTC day of the injected
wall clock, and at each later flush that day until a prune succeeds. ``start`` marks the hour it
ran, so the first write of a boot that succeeds adds that boot's marker row even when nothing was
offered.

The producer marker is ``offered``, counted by ``offer``; the consumer marker is ``written``, the
verdicts a committed ``write_batch`` added to the aggregates. Both reach the store per (boot, hour)
in the transaction of the counts they describe. Bounds (D10): a would-refuse sample beyond
``SAMPLE_BUFFER_LIMIT`` pending samples is not kept and is counted as ``samples_dropped``; a verdict
that needs a new pending key beyond ``PENDING_KEY_LIMIT`` is neither counted in the aggregates nor
sampled, and is counted as ``dropped``; a verdict offered once ``stop`` began is counted in memory
as ``late`` and is not written.
"""

from __future__ import annotations

import asyncio
import logging
import time
import uuid
from typing import TYPE_CHECKING, Any, Final

from probos.admission.store import (
    DAY_SECONDS,
    SAMPLE_RING_SIZE,
    AdmissionShadowStore,
    ShadowBatch,
    ShadowSample,
    utc_hour,
)
from probos.admission.taxonomy import LATENCY_BUCKETS, OUTCOME_ADMIT

if TYPE_CHECKING:
    from collections.abc import Callable

    from probos.admission.record import AdmissionVerdict

logger = logging.getLogger(__name__)

#: D45: seconds between two flushes while the recorder runs.
FLUSH_INTERVAL_SECONDS: Final = 5.0
#: D44: pending would-refuse samples kept between two writes that succeed (the store's ring size).
SAMPLE_BUFFER_LIMIT: Final = SAMPLE_RING_SIZE
#: D44: distinct pending aggregate keys kept between two writes that succeed.
PENDING_KEY_LIMIT: Final = 50_000
#: D45: after the flusher ends, ``stop`` flushes while anything is pending, at most this many times.
STOP_FLUSH_ATTEMPTS: Final = 2
FLUSHER_TASK_NAME: Final = "ad1346-shadow-flusher"
#: The totals ``counters`` returns, in order.
COUNTER_NAMES: Final[tuple[str, ...]] = ("offered", "written", "dropped", "samples_dropped", "late", "flush_failures")
_HOUR_SECONDS: Final = 3_600


def _add(target: dict[Any, int], source: dict[Any, int]) -> None:
    for key, count in source.items():
        target[key] = target.get(key, 0) + count


class ShadowRecorder:
    """Ship's Computer service: counts shadow verdicts in memory and writes them behind (AD-1346 M3b)."""

    def __init__(self, store: AdmissionShadowStore, *, wall_clock: Callable[[], float] = time.time) -> None:
        if not isinstance(store, AdmissionShadowStore):
            raise TypeError("ShadowRecorder needs the AdmissionShadowStore")
        self._store = store
        self._wall_clock = wall_clock
        self._boot_id = uuid.uuid4().hex
        self._hour_index = -1
        self._hour = ""
        self._aggregates: dict[tuple[str, str, str, str, str, int], int] = {}
        self._samples: list[ShadowSample] = []
        self._offered: dict[str, int] = {}
        self._dropped: dict[str, int] = {}
        self._samples_dropped: dict[str, int] = {}
        self._totals: dict[str, int] = dict.fromkeys(COUNTER_NAMES, 0)
        self._pruned_day = -1
        self._stopping = False
        self._stop_requested = asyncio.Event()
        self._task: asyncio.Task[None] | None = None

    @property
    def boot_id(self) -> str:
        """This recorder's boot id in the marker rows: a fresh ``uuid4`` hex per recorder."""
        return self._boot_id

    def offer(self, verdict: AdmissionVerdict, elapsed_ns: int) -> None:
        """Count one verdict in memory and, within the bounds below, aggregate it with its ``decide`` time and sample it when it is not an admit.

        A verdict that needs a new pending key beyond ``PENDING_KEY_LIMIT`` is counted as dropped and
        is neither aggregated nor sampled; a sample beyond ``SAMPLE_BUFFER_LIMIT`` pending samples is
        not kept and is counted as samples_dropped. Once ``stop`` began, it counts the verdict as late
        and keeps nothing. It awaits nothing and does no I/O.
        """
        if self._stopping:
            self._totals["late"] += 1
            return
        now = self._wall_clock()
        hour = self._hour_of(now)
        self._totals["offered"] += 1
        self._offered[hour] = self._offered.get(hour, 0) + 1
        bucket = min(elapsed_ns.bit_length(), LATENCY_BUCKETS - 1)
        key = (hour, verdict.work_kind, verdict.seam, verdict.outcome, verdict.reason_code, bucket)
        if key in self._aggregates:
            self._aggregates[key] += 1
        elif len(self._aggregates) < PENDING_KEY_LIMIT:
            self._aggregates[key] = 1
        else:
            self._totals["dropped"] += 1
            self._dropped[hour] = self._dropped.get(hour, 0) + 1
            return
        if verdict.outcome == OUTCOME_ADMIT:
            return
        if len(self._samples) < SAMPLE_BUFFER_LIMIT:
            self._samples.append(ShadowSample(hour, now, verdict, elapsed_ns))
        else:
            self._totals["samples_dropped"] += 1
            self._samples_dropped[hour] = self._samples_dropped.get(hour, 0) + 1

    def _hour_of(self, now: float) -> str:
        index = int(now // _HOUR_SECONDS)
        if index != self._hour_index:
            self._hour_index = index
            self._hour = utc_hour(index * _HOUR_SECONDS)
        return self._hour

    def start(self) -> None:
        """Mark the current hour for this boot's marker row and start the flusher task.

        Raises ``RuntimeError`` when it has already started or ``stop`` began.
        """
        if self._task is not None or self._stopping:
            raise RuntimeError("AD-1346 M3b: a shadow recorder starts once")
        hour = self._hour_of(self._wall_clock())
        self._offered.setdefault(hour, 0)
        self._task = asyncio.create_task(self._run(), name=FLUSHER_TASK_NAME)

    async def _run(self) -> None:
        while not self._stop_requested.is_set():
            try:
                await asyncio.wait_for(self._stop_requested.wait(), FLUSH_INTERVAL_SECONDS)
            except TimeoutError:
                pass
            await self._flush()

    async def stop(self) -> None:
        """Refuse later offers, let the flusher end after its last flush, then flush what is still pending.

        It waits for the flusher without cancelling it, so this call interrupts no write. Then it
        flushes while anything is pending, at most ``STOP_FLUSH_ATTEMPTS`` times, and logs a warning
        naming what was not written. A flush that raises an ``Exception`` is logged by the flush,
        not raised here.
        """
        self._stopping = True
        self._stop_requested.set()
        task = self._task
        if task is not None:
            await asyncio.wait((task,))
            if not task.cancelled() and task.exception() is not None:
                logger.warning("AD-1346 M3b: the shadow flusher ended with an exception", exc_info=task.exception())
        for _ in range(STOP_FLUSH_ATTEMPTS):
            if not self._pending():
                return
            await self._flush()
        if self._pending():
            logger.warning(
                "AD-1346 M3b: %d shadow verdicts and %d samples were not written before the recorder stopped",
                sum(self._aggregates.values()), len(self._samples),
            )

    async def _flush(self) -> None:
        now = self._wall_clock()
        day = int(now // DAY_SECONDS)
        if day != self._pruned_day:
            try:
                pruned = await self._store.prune(now)
            except Exception:
                self._failed("prune")
            else:
                self._pruned_day = day
                if pruned != (0, 0):
                    logger.info("AD-1346 M3b: the shadow store pruned %d aggregate and %d marker rows", *pruned)
        if not self._pending():
            return
        batch = ShadowBatch(self._aggregates, self._samples, self._offered, self._dropped, self._samples_dropped)
        self._aggregates, self._samples, self._offered, self._dropped, self._samples_dropped = {}, [], {}, {}, {}
        try:
            written = await self._store.write_batch(self._boot_id, batch)
        except BaseException as exc:
            self._restore(batch)
            if not isinstance(exc, Exception):
                raise
            self._failed("write")
            return
        self._totals["written"] += written

    def _restore(self, batch: ShadowBatch) -> None:
        """Add a batch that was not written back to what is pending, keeping at most ``SAMPLE_BUFFER_LIMIT`` samples."""
        _add(self._aggregates, batch.aggregates)
        _add(self._offered, batch.offered)
        _add(self._dropped, batch.dropped)
        _add(self._samples_dropped, batch.samples_dropped)
        kept = batch.samples + self._samples
        for sample in kept[SAMPLE_BUFFER_LIMIT:]:
            self._totals["samples_dropped"] += 1
            self._samples_dropped[sample.hour] = self._samples_dropped.get(sample.hour, 0) + 1
        self._samples = kept[:SAMPLE_BUFFER_LIMIT]

    def _pending(self) -> bool:
        return bool(self._aggregates or self._samples or self._offered or self._dropped or self._samples_dropped)

    def _failed(self, step: str) -> None:
        self._totals["flush_failures"] += 1
        failures = self._totals["flush_failures"]
        logger.log(
            logging.WARNING if failures == 1 else logging.DEBUG,
            "AD-1346 M3b: the shadow store's %s raised (%d failures so far); a batch that was not written stays pending",
            step,
            failures,
            exc_info=True,
        )

    def counters(self) -> dict[str, int]:
        """``COUNTER_NAMES`` and their totals since this recorder was built; a copy."""
        return dict(self._totals)
```

```python
"""AD-1346 M3b (#1604): the read-only queries over ``admission_shadow.db`` (#1601, evidence 2, 7 and 8).

``REPORT_QUERIES`` maps each frozen name to one SELECT. A later slice may add a name; none is
renamed or removed, so the queries the M4 ruling runs keep the names this slice gives them (#1604).
``run_query`` runs one on a connection its caller opened; ``open_read_only`` opens the file with
SQLite's ``mode=ro`` (BF-906), on which every write raises. ``p99_bucket`` reads a latency
histogram built from ``latency_by_work_kind``. No module in ``src`` imports this one (T14 and T16
pin the importers).
"""

from __future__ import annotations

from types import MappingProxyType
from typing import TYPE_CHECKING, Any, Final

from probos.storage.sqlite_factory import default_factory

if TYPE_CHECKING:
    from collections.abc import Mapping, Sequence
    from pathlib import Path

    from probos.protocols import DatabaseConnection

#: AD-1346 M3b (D49): the frozen query names, in order, and their SQL. Append-only.
REPORT_QUERIES: Final[Mapping[str, str]] = MappingProxyType({
    "decisions_by_work_kind": (
        "SELECT work_kind, outcome, reason_code, SUM(decisions) FROM shadow_aggregates WHERE day >= ? "
        "GROUP BY work_kind, outcome, reason_code ORDER BY work_kind, outcome, reason_code"
    ),
    "latency_by_work_kind": (
        "SELECT work_kind, latency_bucket, SUM(decisions) FROM shadow_aggregates WHERE day >= ? "
        "GROUP BY work_kind, latency_bucket ORDER BY work_kind, latency_bucket"
    ),
    "would_refuse_samples": (
        "SELECT seq, boot_id, hour, work_kind, seam, reason_code, latency_ns, verdict_json FROM shadow_samples "
        "ORDER BY seq DESC LIMIT ?"
    ),
    "markers_by_boot": (
        "SELECT boot_id, MIN(hour), MAX(hour), SUM(offered), SUM(written), SUM(dropped), SUM(samples_dropped) "
        "FROM shadow_markers GROUP BY boot_id ORDER BY MIN(hour), boot_id"
    ),
    "days_recorded": "SELECT DISTINCT day FROM shadow_aggregates ORDER BY day",
    "schema_version": "SELECT version FROM schema_version",
})


async def run_query(db: DatabaseConnection, name: str, params: Sequence[Any] = ()) -> list[tuple[Any, ...]]:
    """The rows of the query ``name`` with ``params``, as tuples.

    Raises ``ValueError`` before ``db`` is used when ``name`` is not an exact ``str`` that
    ``REPORT_QUERIES`` holds. An error from ``params`` or from SQLite propagates.
    """
    if type(name) is not str:
        raise ValueError(f"AD-1346 M3b: a shadow report query name is a str, not {type(name).__name__}")
    if name not in REPORT_QUERIES:
        raise ValueError(f"AD-1346 M3b: no shadow report query named {name!r}")
    async with db.execute(REPORT_QUERIES[name], tuple(params)) as cursor:
        return [tuple(row) for row in await cursor.fetchall()]


async def open_read_only(db_path: str | Path) -> DatabaseConnection:
    """A ``mode=ro`` connection to ``db_path`` from the default factory; a missing file raises (BF-906)."""
    return await default_factory.connect(str(db_path), read_only=True)


def p99_bucket(counts: Sequence[int]) -> int | None:
    """The first bucket whose running count reaches 99% of the total, or None when the counts sum to zero or less.

    Bucket b below the last holds ``decide`` times t with ``t.bit_length() == b`` (bucket 0 holds
    0 ns), so 99% of the counted times are below 2**b ns; the last bucket also holds longer times.
    """
    total = sum(counts)
    if total <= 0:
        return None
    running = 0
    for bucket, count in enumerate(counts):
        running += count
        if running * 100 >= total * 99:
            return bucket
    return None
```
