## 1. Problem

- M3e4a left three files `Pending("M3e4b")` (`tests/fixtures/ad1346_store_census.py:97-99`): `cognitive/episodic.py`, `ward_room/messages.py` and `ward_room/threads.py`. No `src` code calls `check_at` with `EFFECT_STORE_WRITE` (`admission/taxonomy.py:33`).
- The Ward Room's content-write entries carry BF-903's guard: `WardRoomService.create_thread` (`ward_room/service.py:417`), `create_post` (`:470`), `edit_post` (`:477`) and `endorse` (`:483`). Each delegates to `self._threads` or `self._messages` on the next line (`:418`, `:471`, `:478`, `:484`).
- `EpisodicMemory.store` (`cognitive/episodic.py:1991`) checks its `duplicate_policy` (`:1998-1999`) before reading the primary collection (`:2000`).
- Neither class holds an admission service.
  - The runtime builds the service at `runtime.py:2966`, only when `admission.shadow_enabled` is true (`:2926`).
  - It binds `self.ward_room` at `:3361` and hands the service to the tool registry, the model gateway and `HttpFetchAgent` at `:3437-3440`.
  - `self.episodic_memory` is the constructor's argument (`:1085`). `__main__.py:619` builds that argument before the runtime exists.
- The SQL write statements of the three files sit in 18 scopes (§11). Some are agent-attributed (posts, edits, endorsements, threads, episodes). Others are the Ward Room's and the memory's own records about agents (credibility, memberships, thread settings, archival, the retention prune, the keyword index), plus the warm-boot and restore copies.
- Hidden pins this slice meets:
  - SK7 requires the functions that call `check_at` to equal a fixed union (`tests/test_ad1346_admission_ticket_sinks.py:511`).
  - T16 pins the `src` files outside `probos/admission/` that import the package (`tests/test_ad1346_admission_service.py:638-650`).

## 2. Solution

- **The checks.**
  - Each of the four Ward Room entries gains `check_at(self._admission, effect=EFFECT_STORE_WRITE, presented_id=<the entry's author_id or voter_id>)` as the statement after BF-903's guard and before its delegating `return`.
  - `EpisodicMemory.store` gains `check_at(self._admission, effect=EFFECT_STORE_WRITE, presented_id=_sole_agent_id(episode))` as the statement after its policy check. `_sole_agent_id` returns the episode's one agent id, or None.
- **The hand-off.**
  - Both classes gain a class-level `_admission: object = None` and an instance `set_admission`.
  - `ProbOSRuntime.start`, beside `HttpFetchAgent.set_admission` (`runtime.py:3440`), hands `self.admission_service` (or None) to `self.ward_room` when it is a `WardRoomService` and to `self.episodic_memory` when it is an `EpisodicMemory`.
- **The census.**
  - `STORE_WRITE_SCOPES` gives each (file, scope) of the three files a `StoreCheck` (5) or a `System` (13). The three files leave `STORE_WRITE_FILES` (76 rows).
  - WC1 requires the scan's scopes in the three files to equal the table's rows exactly, so a new write scope fails it.
  - WM2 checks how the four Ward Room scopes are reached.
- **Shadow only.** `check_at` with None does nothing (`admission/seam.py:52-56`), and the service is None when `admission.shadow_enabled` is false. Nothing is refused, charged or answered differently (WM4).

def _scoped(tree: ast.Module) -> list[tuple[str, ast.AST]]:
    """Each node of one module with its enclosing class and function names, joined as the census joins a scope."""
    found: list[tuple[str, ast.AST]] = []

    def walk(node: ast.AST, scope: tuple[str, ...]) -> None:
        for child in ast.iter_child_nodes(node):
            found.append((".".join(scope) or "<module>", child))
            named = isinstance(child, (ast.ClassDef, ast.FunctionDef, ast.AsyncFunctionDef))
            walk(child, (*scope, child.name) if named else scope)

    walk(tree, ())
    return found


def _holder(node: object, rel: str) -> str | None:
    """The attribute a node reads when it is ``self._messages`` or ``self._threads`` in the Ward Room service, or
    either read from a name or attribute ending in ``ward_room`` in another module; else None."""
    if not isinstance(node, ast.Attribute) or node.attr not in _HOLDERS:
        return None
    base = node.value
    name = base.id if isinstance(base, ast.Name) else base.attr if isinstance(base, ast.Attribute) else ""
    wanted = name == "self" if rel == _SERVICE else name.endswith("ward_room")
    return node.attr if wanted else None
