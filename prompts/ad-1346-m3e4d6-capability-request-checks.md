## 2. Solution

- **The checks (D321).**
  - `CapabilityRequestStore.file_request` calls `check_at(self._admission, effect=EFFECT_STORE_WRITE, presented_id=agent_id)` as the statement before `if self._db:`.
  - `CapabilityRequestStore.decide` calls it, presenting `decided_by`, as its first statement after the docstring. That one check comes before both writers of a decision: `decide`'s UPDATE and its call to `_decide_ladder_row`.
  - The module imports `check_at` and `EFFECT_STORE_WRITE` at module scope.
- **The hand-off (D322).**
  - `CapabilityRequestStore.__init__` gains `admission: object = None` and sets `self._admission`. No method is added: 15 direct methods, and a body of 498 lines (hand count).
  - `init_communication` gains `admission: object = None` and passes it to the store.
  - `ProbOSRuntime.start` passes `admission=self.admission_service`.
- **The rows (D320).** `capability_request.py` leaves `STORE_WRITE_FILES` and `AGENT_ATTRIBUTED_SCOPES`, and is split by scope in `STORE_WRITE_SCOPES`: 3 `StoreCheck` rows (two share `decide`'s check) and 2 `System` rows.
  - `STORE_WRITE_SCOPES` then holds 17 `StoreCheck` and 48 `System` rows in 10 files (hand count).
  - `STORE_WRITE_FILES` holds 69 rows: 2 pending, 66 the ship's, 1 the command line's (hand count).
- **WM1 (D321)** gains a third branch, for a module-level scope that only its check function reaches.
- **Shadow only.** `check_at` does nothing unless it is handed an exact `AdmissionService` (`admission/seam.py:60-62`). Nothing is refused, charged or answered differently (WM17).

async def _capability_round(store: CapabilityRequestStore, phase: int) -> list[object]:
    """AD-1346 M3e4d6: one round of four checked writes, a filing by ``AGENT_A`` that ``AGENT_B`` decides and a filing
    with a ladder record by ``AGENT_B`` that ``AGENT_A`` decides, then an install filing with an invalid payload, which
    ``file_request`` refuses before its check. Returns each answer without the fields a fresh store draws, and the
    refusal's text."""
    filed = await store.file_request(AGENT_A, "grant", f"ad1346-m3e4d6-alpha-{phase}", rationale=f"ad1346 m3e4d6 bravo {phase}")
    decided = await store.decide(filed.id, True, reason=f"ad1346 m3e4d6 charlie {phase}", decided_by=AGENT_B)
    ladder = await store.file_request(
        AGENT_B, "grant", f"ad1346-m3e4d6-delta-{phase}", rationale=f"ad1346 m3e4d6 echo {phase}", triage=_REQUEST_LADDER,
    )
    settled = await store.decide(ladder.id, False, reason=f"ad1346 m3e4d6 foxtrot {phase}", decided_by=AGENT_A)
    refused: list[str] = []
    try:
        await store.file_request(AGENT_A, "install", f"ad1346-m3e4d6-golf-{phase}", payload={})
    except ValueError as exc:
        refused.append(str(exc))
    return [_shape(filed), _shape(decided), _shape(ladder), _shape(settled), refused]
