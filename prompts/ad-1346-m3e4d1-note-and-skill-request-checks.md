## 2. Solution

- **The checks (D285).**
  - `write_note` gains `check_at(self._admission, effect=EFFECT_STORE_WRITE, presented_id=author_agent_id)`.
  - `file_request` gains the same with `presented_id=agent_id`.
  - `decide` gains the same with `presented_id=decided_by`.
  - Each is the statement before the scope's `if self._db:`.
- **The hand-off (D286).** Both classes gain a class-level `_admission: object = None` and an instance `set_admission`. `ProbOSRuntime.start` hands `self.admission_service` (or None) to each store under `isinstance`, beside the M3e4b hand-offs.
- **The rows (D284).** Both files leave `STORE_WRITE_FILES` and `AGENT_ATTRIBUTED_SCOPES` and are split by scope in `STORE_WRITE_SCOPES`: 3 `StoreCheck` rows and 2 `System` rows. `STORE_WRITE_SCOPES` then holds 8 checks and 15 `System` rows in 5 files. `STORE_WRITE_FILES` holds 74 rows: 7 pending, 66 the ship's, 1 the command line's.
- **Shadow only.** `check_at` with None does nothing (`admission/seam.py:53-57`). Nothing is refused, charged or answered differently (WM7).
