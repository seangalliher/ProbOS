## 2. Solution

- **Two sinks.**
  - `SubprocessSandbox.run` gains one statement after its workdir block and before the `try` that hands `_run_sync` to the executor: `check_at(self._admission, effect=EFFECT_SUBPROCESS, presented_id=None)`. `self._admission` comes from a new constructor keyword, `admission_service` (default None). The code runner's two constructions and the tool's two pass `getattr(self._runtime, "admission_service", None)`; `SkillForge._smoke_test`'s passes none.
  - `DependencyResolver._install_package` gains the same statement after its `install_fn` return and before its fallback chain. `self._admission` is set by a new `set_admission`, which `ProbOSRuntime.start` calls right after it keeps the resolver.
  - With no service, or anything but an exact `AdmissionService`, `check_at` does nothing.
- **The census** (`tests/fixtures/ad1346_effect_census.py`):
  - `Sink` gains `service` (default `SERVICE_EXPR`) and `via` (the functions between the check and the launching one);
  - a fifth coverage, `Unreached(names, reason)`;
  - the 11 pending launches become 2 sink rows (4 launches), 2 system rows (3), 3 unreached rows (3) and 1 pending row owned by `M3e2b` (1).
- **The totals.** Sink 11 launches in 7 rows, System 19, OutsideRuntime 5, Unreached 3, Pending 1; 39 in all, BF-892's floor.
- **The guards.** EC3 checks each sink's service form and follows `via`; EC4 checks each link of a chain; SP1 checks that no other `src` code references an unreached row's names; SP3 pins the wiring by AST.
- **The crossing test** (SP4) and **the golden test** (SP5) drive the real tool, sandbox and installer, with each launch replaced and `subprocess.Popen` replaced by a recorder that raises.

def _reaching(node: ast.AST, outer: str, own: bool, wanted: frozenset[str], found: list[int]) -> None:
    for child in ast.iter_child_nodes(node):
        if isinstance(child, (ast.ClassDef, ast.FunctionDef, ast.AsyncFunctionDef)):
            _reaching(child, outer or child.name, own, wanted, found)
            continue
        if isinstance(child, (ast.Import, ast.ImportFrom)):
            dotted = [alias.name for alias in child.names] + [getattr(child, "module", None) or ""]
            hit = any(part in wanted for name in dotted for part in name.split("."))
        elif isinstance(child, ast.Attribute):
            hit = child.attr in wanted and (own or not (isinstance(child.value, ast.Name) and child.value.id == "self"))
        else:
            hit = isinstance(child, ast.Name) and child.id in wanted
        if hit and not (own and outer in wanted):
            found.append(child.lineno)
        _reaching(child, outer, own, wanted, found)

def _no_launch(monkeypatch: pytest.MonkeyPatch) -> tuple[list[object], list[object]]:
    """Replace the sandbox's launching function and ``subprocess.run``; make ``subprocess.Popen`` a recorder that raises."""
    popen: list[object] = []
    ran: list[object] = []

    def no_popen(*args: Any, **kwargs: Any) -> Any:
        popen.append(args)
        raise OSError("ad1346-m3e2a: no process is started")

    def run(argv: list[str], **kwargs: Any) -> subprocess.CompletedProcess[str]:
        ran.append(argv)
        return subprocess.CompletedProcess(argv, 0, stdout=INSTALLED, stderr="")

    def inner(self: SubprocessSandbox, request: ExecutionRequest) -> ExecutionResult:
        return ExecutionResult(success=True, stdout=STDOUT, exit_code=0)

    monkeypatch.setattr(subprocess, "Popen", no_popen)
    monkeypatch.setattr(subprocess, "run", run)
    monkeypatch.setattr(SubprocessSandbox, "_run_sync_inner", inner)
    return popen, ran
