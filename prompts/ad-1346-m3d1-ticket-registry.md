## 1. Problem

- #1604 property 9 and the design note's rules 2 and 3 need a ticket registry. A sink must accept a ticket only when its id is live in the registry, and must read principal, scope, budget and parent from the registry's entry. A child ticket must be a subset of its parent, and its depth must be bounded. Production must refuse a `TestTicket`. Every denial must carry a code and a human-readable cause. No such type exists on this tree (Absence).
- Property 5 ("a Captain stop records a would-refuse at an in-flight agentic run's next model or tool call, and at a delegated child's") needs revocation that reaches a child whose own principal is not stopped. On this tree the tool sink asks only about the calling agent: `tool_refusal(self._stop_gate, agent_id, tool_id)` (`src/probos/tools/registry.py:396`).
- The vocabulary that keys the shadow store's bounds is `REASON_CODES` (`src/probos/admission/taxonomy.py:60-66`, 4 codes).
  - P13 requires `len(WORK_KINDS) * len(SEAMS) * len(TODAY_OUTCOMES) * len(REASON_CODES) * AGGREGATE_RETENTION_DAYS < AGGREGATE_ROW_LIMIT` (`tests/test_ad1346_admission_shadow_parity.py:449-450`). That is 12 × 12 × 2 × 4 × 35 = 40,320 < 100,000 on this tree.
  - Any ticket code added to that tuple multiplies the product (D93).
- Hidden pins this slice meets:
  - T14 requires the package's files to be exactly its allowlist's keys (`tests/test_ad1346_admission_service.py:495`).
  - In a decision file T14 forbids `await` and the async forms (`:519`) and every call name in `_FORBIDDEN_CALLS` (`:104-107`; among them `open`, `sleep`, `Lock`, `acquire`, `connect`, `execute`, `create_task` and `run_in_executor`), and it allows `logger` only in `service.py` (`:518-525`).
  - T14's docstring says "logging and the clock only in shadow" (`:491`), which a second decision file that reads a clock would falsify.
  - T15 runs the seam census over the package (`:538-547`).
  - The SRP check fires on a class of more than 500 lines or more than 15 direct methods (`SRP_MAX_BODY_LINES = 500`, `SRP_MAX_DIRECT_METHODS = 15`, `scripts/check_architecture_principles.py:187-188`; `span >` at `:566`, `methods >` at `:568`).

## 2. Solution

- **Vocabulary.** `taxonomy.py` gains twelve ticket codes in `TICKET_REASON_CODES`: a second closed tuple of the one taxonomy, in the AD-1316 syntax and disjoint from `REASON_CODES`. An `AdmissionVerdict` never carries a ticket code, so the store's per-day bounds do not move.
- **Library.** `probos.admission.tickets` defines these types:
  - `WorkTicket`: an id only.
  - `TestTicket`.
  - `TicketScope`: the effect points.
  - `TicketBudget`: two ceilings.
  - `TicketEntry`: the registry's record.
  - `TicketFinding`, with the append-only `TICKET_FINDING_KEYS`.
  - `TicketIssue`.
  - `TicketRegistry`, with these public methods: `issue`, `issue_child`, `check`, `revoke`, `release`, `entry`, `tally` and `__len__`.
- **Authority.** `check` and `issue_child` read what they compare from the registry's entry for the presented id, never from the presented object.
- **Revocation.** `revoke` reaches every registered descendant. `check` reads a Captain's stop with `stop_for` for the entry's principal and each registered ancestor's, then marks that subtree revoked for good.
- **Bounds.** At most `MAX_TICKETS` entries. An issue first drops entries from the oldest while the oldest ended more than `retain_seconds` ago, so an ended entry stays while an older one is live (D97).
- **No caller.** Nothing in `src` calls the module (K15). M3d2 and M3d3 are scoped in the register (R29, R30).

## 3. Decisions (numbered after M3c3's D79 to D89)

- **D90 Three slices.** This slice is the library. M3d2 adds the issue points, the carrier and the service wiring with a golden test. M3d3 adds the sink checks at the tool sink and the model gateway, the persisted sink record, the census and the crossing tests of property 5.
  - Reason: the library ships alone, as M3a's package did with no caller. Each later slice then reviews one census.
  - Rejected: one M3d slice (the registry, the issue census and both sinks in one review); two slices (the registry and the issue census in one review); sinks first (they would record only `ticket_missing`).
- **D91 In memory, with no store and no restore.** The registry is built empty on each start. Work in flight at a restart is admitted again at its seam (M3d2).
  - Nothing is persisted, so no older build reads anything this slice writes, and `SCHEMA_VERSION` (`store.py:56`) does not move.
  - Rejected: a rebuild from `admission_shadow.db` (a restored ticket would carry authority across a restart, and the bound would then also have to hold on the restore path); a table written on issue (I/O on the issue path, #1604 blind spot 3).
- **D92 Data types and key sets.**
  - `WorkTicket(ticket_id)`: the id is 128 random bits (`secrets.token_hex(16)`, as `execution/effect_broker.py:367` mints a nonce); `__post_init__` requires an exact `str`.
  - `TestTicket(label="")`: not a `WorkTicket`; `__test__ = False`.
  - `TicketScope(effects)`: a frozenset within `TICKET_EFFECTS`.
  - `TicketBudget(max_tokens, max_iterations)`: each None or an exact int of at least 1.
  - `TicketEntry`: the in-memory record. It is never serialised, so it has no key set.
  - `TicketFinding`: its `to_dict()` follows `TICKET_FINDING_KEYS` (operation, code, cause, ticket_id, principal_key, presented_key, parent_id, depth, work_kind, stop_id). That key set is append-only, as `VERDICT_KEYS` is (`record.py:29-33`), because M3d3 plans to persist findings.
  - `TicketIssue(ticket, finding)`.
  - The records are frozen with slots.
  - Rejected: copies of scope and principal on `WorkTicket` (they invite a sink to read the presented object, which is MS14-068's failure in the design note).
- **D93 The ticket codes.** In order: `ticket_issued`, `ticket_live`, `ticket_missing`, `ticket_unknown`, `ticket_test_refused`, `ticket_revoked`, `ticket_expired`, `ticket_principal_mismatch`, `ticket_out_of_scope`, `ticket_widened`, `ticket_too_deep`, `ticket_registry_full`. No cause carries the Captain's reason: the registry reads only the stop record's `stop_id` (K11 pins it for the findings it checks).
  - `REASON_CODES`, P13 (1,152 × 35 = 40,320) and S9 (23,040) are unchanged.
  - Rejected: appending to `REASON_CODES` (16 codes give 161,280 parity rows in 35 days, above `AGGREGATE_ROW_LIMIT`); a subset of at most 5 codes there (90,720 rows, too little headroom for M3e's seams); one `ticket_invalid` code.
- **D94 Scope and budget in a slice that charges nothing.**
  - Scope names the effect points a unit's work may reach: `TICKET_EFFECTS = (SEAM_TOOL, SEAM_MODEL_CALL)`, imported from `agent_stop` and `taxonomy`.
  - Budget is two ceilings, matching the run's `max_iterations` and `token_budget` arguments (`agentic_dispatch.py:2674-2677`) and the tree ceilings of `TreeCeilings` (`delegation_budget.py:82-93`). They are compared at a child's issue and never decremented; M5 owns accounts.
  - Rejected: tool-id scope (that is M3f's `scope_clearance`, register R34); an opaque scope.
- **D95 Child tickets.**
  - A child is one level deeper than its parent's entry, at most `max_depth`.
  - Its scope is a subset of the parent's.
  - A ceiling the child leaves None is the parent's; a ceiling it sets is at most the parent's when the parent has one.
  - Its expiry is `min(now + ttl, parent.expires_at)`.
  - Refusals: a parent that is not live is refused with its own code; a deeper child with `ticket_too_deep`; a wider child with `ticket_widened`. A refusal adds no entry.
  - `max_depth` is the value `delegation_max_depth` holds (`config_models/agentic.py:1025`, default 1, bounds 0 to 3). `DelegateTaskTool` enforces that bound (`delegate_task_tool.py:323`) and hands it to `DelegationTreeBudget.admit` (`:416-420`).
  - Reframed from "bounded by `DelegationTreeBudget`": that object holds no depth and is None when no tree ceiling is set (`delegation_budget.py:236-242`). The bound is the same one, so nothing is weakened.
- **D96 Revocation.**
  - `revoke(ticket)` marks a registered entry and each registered descendant revoked, and returns the count.
  - `check` (and `issue_child`, for a parent) reads `AgentStopService.stop_for` for the entry's principal and then for each registered ancestor's. The first entry found under a stop is revoked with its subtree and keeps the order's `stop_id`. It stays revoked after a lift.
  - `stop_for` counts nothing (`agent_stop.py:376-380`; `refusal` counts at `:389-390`), which keeps #1604 property 10's constraint.
  - The stop path gains no hook, so the Captain's routes stay ungated (#1604 property 11).
  - Rejected: a listener from `issue_stop` into the registry (the stop would then depend on the gate); a revocation generation on `AgentStopService` (that changes S1's service, which parity measures against; deferred to M4, register R32).
- **D97 Bounds (F-209).**
  - `MAX_TICKETS = 50_000`, `TICKET_TTL_SECONDS = 3_600.0` on the injected clock (`time.monotonic` by default), `TICKET_RETAIN_SECONDS = 600.0`, `SHOWN_CHARS = 64` (the longest id or key a finding carries).
  - `issue` and `issue_child` add an entry only through `_register`. `_register` first drops entries in issue order (a `deque`) while the oldest one ended more than `retain_seconds` ago. If `MAX_TICKETS` entries still remain, it refuses with `ticket_registry_full`.
  - There is no restore or retry path that adds an entry, so the bound holds on every insertion.
  - `_children` keys are a subset of the entries' keys. The tally's keys come from closed tuples: at most 3 × 12 = 36.
  - The purge is head-of-line: an entry that ended stays while an older entry is still live (the orchestrator's pre-build run, 2026-10-30: a root A issued at t=0 and left live (default TTL 3,600 seconds), a root B issued at t=0 and released at t=10, then a third issue at t=1,000 with the default `retain_seconds` of 600, B having ended 990 seconds earlier: the registry held 3 entries, B kept; when A was not issued, it held 1 entry, B dropped). The registry's size therefore depends on how long its oldest live ticket lives (a root up to `TICKET_TTL_SECONDS`), not only on the work in flight; the shadow evidence calibrates it (register R33).
  - Rejected: evicting live tickets; expiry only; weak references.
- **D98 Forgery and the test ticket.**
  - The registry's entry decides. An object that is not exactly a `WorkTicket` is `ticket_unknown` (None is `ticket_missing`; a `TestTicket` is handled by the next rule). That covers a subclass carrying a wider scope, a look-alike, and a `WorkTicket` built without `__init__`.
  - A `WorkTicket` built by hand with a live id resolves to that entry (K4).
  - `allow_test_tickets` defaults to False. In a registry built with it, a `TestTicket` is `ticket_live` at any effect and parents nothing. Any other registry answers `ticket_test_refused`.
  - K5 pins that no `src` file but `tickets.py` names `TestTicket` or `allow_test_tickets`.
  - Rejected: detecting pytest from process state; a config field; no test type at all (ranked second).
- **D99 Threads and exceptions.**
  - The registry holds no lock and awaits nothing (T14). Like `DelegationTreeBudget` (`delegation_budget.py:171-175`), it is to be used only from the thread that runs its event loop.
  - On this tree a model call runs on a worker thread's own loop (`consultation/llm_decomposer.py:148-149`), so M3d3 decides what a sink check on another thread does (register R31).
  - Raising contract: `check` raises no `Exception` for any presented ticket. Arguments the caller controls raise `ValueError` or `TypeError` (an `effect` outside `TICKET_EFFECTS`, a non-`str` `presented_key`, issue arguments outside their sets, wrong constructor types), as `decide` propagates its own (T12).
  - The registry raises no `BaseException` of its own. A `BaseException` raised by an injected clock propagates.
  - M3d2 and M3d3 call the registry inside the service's `except Exception` (`service.py:117`).
- **D100 Cost.** No caller, so no hot-path cost in this slice, and M3c1's D64 measurement still holds.
  - Measured (the orchestrator's pre-build run, 2026-10-30): a `check` at `SEAM_TOOL` of a live ticket at depth 3 (a root and three children, `max_depth` 3, the most `delegation_max_depth` allows; no stop in force; its principal as `presented_key`), counting `get` and `[]` on the registry's `_entries` and `_tally` and the stop service's `_active`, did 10 reads (5, 1 and 4) and one tally write. The first check that finds a stop also walks that subtree once (read from the source, not measured).
  - M3d3 measures `decide()` plus the sink check (#1604 property 7).
- **D101 The carrier (binding direction for M3d2).**
  - One module `ContextVar[WorkTicket | None]` (default None). It is set with a token and reset in `finally` around the admitted work, never set without a reset. It is an observation device only; M4 decides on explicit threading (slice plan D11 to D17).
  - Python 3.12 documentation (`requires-python = ">=3.12"`, `pyproject.toml:9`):
    - `asyncio.create_task`: "The current context copy is created when no _context_ is provided."
    - `asyncio.to_thread`: "the current contextvars.Context is propagated".
    - `loop.run_in_executor`: says nothing about context, so a call made through an executor, or through `ThreadPoolExecutor.submit` as at `llm_decomposer.py:149`, is treated as carrying no ticket.
  - A sink with no ticket records `ticket_missing` and never blocks in shadow. No "no ticket means allowed" path exists: the only test path is `TestTicket`, which production refuses (D98).
- **D102 Issue points and children (binding direction for M3d2, which re-verifies them by census).**
  - Issue on the admit path of `CognitiveAgent.handle_intent`, `CognitiveAgent.handle_consultation_request` and `WorkItemAgenticExecutor.run` (`agentic_dispatch.py:2709`).
  - A child ticket is issued when the carrier already holds a live ticket. `DelegateTaskTool` awaits the child's run inline (`delegate_task_tool.py:494`), so the run entry sees the parent's ticket. Crew children started as tasks inherit it through the context copy.

    def issue_child(
        self, parent: object, *, principal_key: str, work_kind: str, seam: str, scope: TicketScope,
        budget: TicketBudget,
    ) -> TicketIssue:
        """Register a child of the live, registered ``parent``, checked against the parent's entry (the design note's rule 3).

        The child is one level deeper and at most ``max_depth``; its scope is a subset of the parent's; each
        ceiling it leaves None is the parent's, and each it sets is no larger than a ceiling the parent has; it
        expires no later than the parent. A parent that is not live is refused with its own code, a deeper child
        with ``ticket_too_deep`` and a wider one with ``ticket_widened``; a refusal adds no entry.

        parent_entry, found = self._liveness(parent, now, OP_ISSUE, "")
        if parent_entry is None or found.code != TICKET_LIVE:
            cause = f"No child was issued: {found.cause}"
            return _refusal(self._tally, found.code, cause, principal_key, work_kind, found.ticket_id, 0, found.stop_id)

        if depth > self._max_depth:
            cause = f"No child was issued: a child of ticket {parent_entry.ticket_id} would be at depth {depth}, beyond {self._max_depth}."
            return _refusal(self._tally, TICKET_TOO_DEEP, cause, principal_key, work_kind, parent_entry.ticket_id, depth, "")

        iterations = parent_entry.budget.max_iterations if budget.max_iterations is None else budget.max_iterations

        wider_iterations = not _within(iterations, parent_entry.budget.max_iterations)
        if wider_scope or wider_tokens or wider_iterations:
            cause = f"No child was issued: its scope or a ceiling is wider than ticket {parent_entry.ticket_id}'s."
            return _refusal(self._tally, TICKET_WIDENED, cause, principal_key, work_kind, parent_entry.ticket_id, depth, "")

            principal_key, work_kind, seam, scope, TicketBudget(tokens, iterations), parent_entry, now, expires_at,

    def check(self, ticket: object, *, effect: str, presented_key: str = "") -> TicketFinding:
        """The liveness check an effect point runs (#1601 Target 2): the counted finding for ``ticket`` at ``effect``.

        In order: no ticket is ``ticket_missing``; a ``TestTicket`` is ``ticket_live`` in a registry built for
        tests; then ``_liveness`` (``ticket_test_refused``, ``ticket_unknown``, ``ticket_revoked``,
        ``ticket_expired``, or ``ticket_revoked`` under a Captain's stop); then ``ticket_principal_mismatch``
        when ``presented_key`` is given and is not the entry's principal, ``ticket_out_of_scope`` when
        ``effect`` is not in the entry's scope, else ``ticket_live``. It raises no ``Exception`` for any
        presented ``ticket``. An ``effect`` outside ``TICKET_EFFECTS`` raises ``ValueError``, and a
        ``presented_key`` that is not a ``str`` raises ``TypeError``.
        """
        if type(effect) is not str or effect not in _EFFECT_SET:
            raise ValueError(f"AD-1346: unknown effect {effect!r}")
        if type(presented_key) is not str:
            raise TypeError("AD-1346: presented_key is a str")
        shown_key = _shown(presented_key)
        if ticket is None:
            missing = TicketFinding(effect, TICKET_MISSING, f"No ticket was presented at {effect}.", presented_key=shown_key)
            return _counted(self._tally, missing)
        if type(ticket) is TestTicket and self._allow_test:
            cause = f"A TestTicket is live at {effect} in a registry built for tests."
            return _counted(self._tally, TicketFinding(effect, TICKET_LIVE, cause, presented_key=shown_key))
        entry, found = self._liveness(ticket, self._clock(), effect, shown_key)
        if entry is None or found.code != TICKET_LIVE:
            return _counted(self._tally, found)
        if presented_key and presented_key != entry.principal_key:
            cause = f"Ticket {entry.ticket_id} is registered to {_shown(entry.principal_key)}, not to {shown_key}."
            return _counted(self._tally, replace(found, code=TICKET_PRINCIPAL_MISMATCH, cause=cause))
        if effect not in entry.scope.effects:
            cause = f"Ticket {entry.ticket_id}'s scope does not include {effect}."
            return _counted(self._tally, replace(found, code=TICKET_OUT_OF_SCOPE, cause=cause))
        cause = f"Ticket {entry.ticket_id} of {_shown(entry.principal_key)} is live at {effect}."
        return _counted(self._tally, replace(found, cause=cause))

    def revoke(self, ticket: object) -> int:
        """Revoke a registered ticket and its registered descendants; return how many entries this revoked.

        The issuer's act (AD-1346 M4 decides who calls it). Anything not registered revokes nothing and returns 0.
        """
        ticket_id = _presented_id(ticket)
        if ticket_id is None or ticket_id not in self._entries:
            return 0
        return self._revoke_tree(ticket_id, self._clock(), "")

    def release(self, ticket: object) -> bool:
        """End a registered ticket's life now, as its work ends; a later check reads ``ticket_expired`` unless it is revoked.

        False for anything not registered. Its children keep their own expiry.
        """
        ticket_id = _presented_id(ticket)
        entry = None if ticket_id is None else self._entries.get(ticket_id)
        if entry is None:
            return False
        now = self._clock()
        if now < entry.expires_at:
            self._entries[entry.ticket_id] = replace(entry, expires_at=now)
        return True

    def entry(self, ticket: object) -> TicketEntry | None:
        """The registry's entry for a presented ticket's id, live or ended and not yet dropped, or None.

        What a sink reads; never the presented object.
        """
        ticket_id = _presented_id(ticket)
        return None if ticket_id is None else self._entries.get(ticket_id)

    def tally(self) -> dict[tuple[str, str], int]:
        """Findings by (operation, code) since this registry was built; a copy."""
        return dict(self._tally)

    def _register(
        self, principal_key: str, work_kind: str, seam: str, scope: TicketScope, budget: TicketBudget,
        parent: TicketEntry | None, now: float, expires_at: float,
    ) -> TicketIssue:
        """Add one entry after ``_purge``, unless ``MAX_TICKETS`` entries remain."""
        self._purge(now)
        parent_id = "" if parent is None else parent.ticket_id
        depth = 0 if parent is None else parent.depth + 1
        if len(self._entries) >= MAX_TICKETS:
            cause = f"The ticket registry holds {len(self._entries)} tickets, its bound; none was issued."
            return _refusal(self._tally, TICKET_REGISTRY_FULL, cause, principal_key, work_kind, parent_id, depth, "")
        ticket_id = secrets.token_hex(16)
        self._entries[ticket_id] = TicketEntry(
            ticket_id, principal_key, work_kind, seam, scope, budget, parent_id, depth, now, expires_at,
        )
        self._order.append(ticket_id)
        if parent is not None:
            self._children.setdefault(parent_id, set()).add(ticket_id)
        cause = f"Ticket {ticket_id} issued to {_shown(principal_key)} for {work_kind} at {seam}, depth {depth}."
        finding = TicketFinding(
            OP_ISSUE, TICKET_ISSUED, cause, ticket_id=ticket_id, principal_key=_shown(principal_key),
            parent_id=parent_id, depth=depth, work_kind=work_kind,
        )
        return TicketIssue(WorkTicket(ticket_id), _counted(self._tally, finding))

    def _purge(self, now: float) -> None:
        """Drop entries in issue order while the oldest ended more than ``retain_seconds`` before ``now``."""
        while self._order:
            oldest = self._entries[self._order[0]]
            if now - _ended(oldest) <= self._retain:
                return
            self._order.popleft()
            del self._entries[oldest.ticket_id]
            self._children.pop(oldest.ticket_id, None)

    def _liveness(
        self, ticket: object, now: float, operation: str, presented_key: str,
    ) -> tuple[TicketEntry | None, TicketFinding]:
        """The registered entry for a presented ticket and its finding: ``ticket_test_refused``, ``ticket_unknown``,
        ``ticket_revoked``, ``ticket_expired``, then a Captain's stop on its principal or an ancestor's
        (``ticket_revoked``), else ``ticket_live`` with no cause yet."""
        if type(ticket) is TestTicket and not self._allow_test:
            cause = "A TestTicket was presented to a registry that refuses test tickets."
            return None, TicketFinding(operation, TICKET_TEST_REFUSED, cause, presented_key=presented_key)
        ticket_id = _presented_id(ticket)
        entry = None if ticket_id is None else self._entries.get(ticket_id)
        if entry is None:
            shown = "" if ticket_id is None else _shown(ticket_id)
            cause = "The presented object is not a ticket the registry holds."
            return None, TicketFinding(operation, TICKET_UNKNOWN, cause, ticket_id=shown, presented_key=presented_key)
        found = TicketFinding(
            operation, TICKET_LIVE, "", ticket_id=entry.ticket_id, principal_key=_shown(entry.principal_key),
            presented_key=presented_key, parent_id=entry.parent_id, depth=entry.depth, work_kind=entry.work_kind,
        )
        if entry.revoked_at is not None:
            cause = _revoked_cause(entry.ticket_id, entry.stop_id)
            return entry, replace(found, code=TICKET_REVOKED, cause=cause, stop_id=entry.stop_id)
        if now >= entry.expires_at:
            cause = f"Ticket {entry.ticket_id} ended: it expired, or was released when its work ended."
            return entry, replace(found, code=TICKET_EXPIRED, cause=cause)
        node: TicketEntry | None = entry
        while node is not None:
            record = self._stops.stop_for(node.principal_key)
            if record is not None:
                self._revoke_tree(node.ticket_id, now, record.stop_id)
                cause = _revoked_cause(entry.ticket_id, record.stop_id)
                return entry, replace(found, code=TICKET_REVOKED, cause=cause, stop_id=record.stop_id)
            node = self._entries.get(node.parent_id)
        return entry, found

    def _revoke_tree(self, ticket_id: str, now: float, stop_id: str) -> int:
        """Mark a registered entry and each registered descendant revoked at ``now``; return how many were not already."""
        revoked = 0
        pending = [ticket_id]
        while pending:
            current = self._entries.get(pending.pop())
            if current is None:  # a dropped id holds nothing to revoke
                continue
            if current.revoked_at is None:
                self._entries[current.ticket_id] = replace(current, revoked_at=now, stop_id=stop_id)
                revoked += 1
            pending.extend(self._children.get(current.ticket_id, ()))
        return revoked


def _shown(value: str) -> str:
    """An id or a key as a finding carries it: at most ``SHOWN_CHARS`` characters."""
    return value[:SHOWN_CHARS]


def _ended(entry: TicketEntry) -> float:
    """When an entry stopped being live: its expiry, or its revocation when that came first."""
    return entry.expires_at if entry.revoked_at is None else min(entry.expires_at, entry.revoked_at)


def _within(child: int | None, parent: int | None) -> bool:
    """A child's ceiling is no wider than the parent's: anything under an unbounded parent, else a value at most the parent's."""
    return parent is None or (child is not None and child <= parent)


def _presented_id(ticket: object) -> str | None:
    """The id of an exact ``WorkTicket``; None for any other object, and for one built without its id."""
    if type(ticket) is WorkTicket:
        try:
            ticket_id = ticket.ticket_id
        except AttributeError:  # built with object.__new__: the slot is empty
            return None
        return ticket_id if type(ticket_id) is str else None
    return None


def _revoked_cause(ticket_id: str, stop_id: str) -> str:
    """Why a ticket is revoked: the Captain's stop by its order's id, or its issuer; never the Captain's reason."""
    if stop_id:
        return f"Ticket {ticket_id} is revoked: its principal or an ancestor's is under the Captain's stop {stop_id}."
    return f"Ticket {ticket_id} is revoked by its issuer, itself or with an ancestor."


def _require(principal_key: object, work_kind: object, seam: object, scope: object, budget: object) -> None:
    """An issue's arguments: str values, a non-empty principal key, a known work kind and seam, a TicketScope and a TicketBudget."""
    for value in (principal_key, work_kind, seam):
        if type(value) is not str:
            raise TypeError("AD-1346: a ticket's principal key, work kind and seam are str")
    if not principal_key or work_kind not in WORK_KINDS or seam not in SEAMS:
        raise ValueError(f"AD-1346: an empty principal key, or an unknown work kind or seam: {work_kind!r}, {seam!r}")
    if type(scope) is not TicketScope or type(budget) is not TicketBudget:
        raise TypeError("AD-1346: a ticket takes a TicketScope and a TicketBudget")


def _counted(tally: dict[tuple[str, str], int], finding: TicketFinding) -> TicketFinding:
    """Count a finding under (operation, code) and return it."""
    key = (finding.operation, finding.code)
    tally[key] = tally.get(key, 0) + 1
    return finding


def _refusal(
    tally: dict[tuple[str, str], int], code: str, cause: str, principal_key: str, work_kind: str, parent_id: str,
    depth: int, stop_id: str,
) -> TicketIssue:
    """An issue that added no entry: no ticket, and its counted finding."""
    finding = TicketFinding(
        OP_ISSUE, code, cause, principal_key=_shown(principal_key), parent_id=parent_id, depth=depth,
        work_kind=work_kind, stop_id=stop_id,
    )
    return TicketIssue(None, _counted(tally, finding))

## 14. Diff Reviewer: properties to verify

1. **Authority.**
   - `check`, `issue_child`, `entry`, `revoke` and `release` take the id only from an exact `WorkTicket` (`_presented_id`), and read principal, scope, budget, parent and expiry only from `self._entries`.
   - No attribute of the presented object other than `ticket_id` is read.
2. **Test tickets.**
   - `allow_test_tickets` defaults to False.
   - A `TestTicket` is `ticket_test_refused` in such a registry, at every effect and as a parent.
   - In a test registry it is `ticket_live` at a check and parents nothing.
   - No `src` file but `tickets.py` names `TestTicket` or `allow_test_tickets` (K5).
3. **Attenuation.**
   - A child's depth is `parent.depth + 1` and at most `max_depth`.
   - `scope.effects` is a subset of the parent's.
   - An unset ceiling becomes the parent's; a set one is at most the parent's when the parent has one.
   - `expires_at` is at most the parent's.
   - Each refusal adds no entry.
4. **Revocation.**
   - `revoke` marks the subtree.
   - The stop walk starts at the entry, follows `parent_id`, calls only `stop_for`, and marks from the stopped node down with the order's `stop_id`.
   - A revoked entry stays revoked after a lift.
   - No cause includes the stop's reason.
5. **Bounds.**
   - `_register` is the only insertion, after `_purge`.
   - `_order` and `_entries` stay in step.
   - `MAX_TICKETS` is read at call time.
   - The tally's keys come from closed tuples.
   - No path restores entries.
6. **No raise, no lock, no I/O.**
   - `check` raises no `Exception` for any presented ticket.
   - No `await`, lock, logger, file or connection (T14).
   - The registry writes no trust, budget or stop state. Its one call on the stop service is `stop_for` (by grep, D105); T15 pins that the package calls no guard callee and no agent-work call, and K11 that the stop's refusal counts stay empty.
7. **Vocabulary.**
