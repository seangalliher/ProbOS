## 2. Solution

- **`http_fetch`.** `HttpFetchAgent` gets a class-level `_admission` and `set_admission`. `ProbOSRuntime.start` calls `HttpFetchAgent.set_admission(self.admission_service)`, and shutdown calls `HttpFetchAgent.set_admission(None)`. `_fetch_url` calls `check_at(self._admission, effect=EFFECT_EGRESS, presented_id=None)` after the method refusal and before `_validate_url`.
- **The red team.** `_verify_http_fetch` calls `check_at(getattr(getattr(self, "_runtime", None), "admission_service", None), effect=EFFECT_EGRESS, presented_id=None)` after its method refusal and before the request's `try`.
- **The image endpoint.** `dispatch_image_gen` calls `check_at(getattr(runtime, "admission_service", None), effect=SEAM_MODEL_CALL, presented_id=agent_id)` before the request's `try`.
- **The census.**
  - The `http_fetch` and red team rows become `Sink` rows.
  - The image row becomes `OtherClass("model_call", ...)`.
  - The browser rows' owner becomes `M3e3c`.
  - The counts become 2 sink, 2 pending, 2 other-class, 28 system in 27 rows, 2 reached only from named files and 7 command-line in 5 rows: 43 points in 40 rows.
- **Nothing is refused.** `check_at` returns None. It raises only what `check_ticket` raises, and the real `check_ticket` lets no `Exception` out (`admission/seam.py:49-53`; `admission/service.py:230-239`).

def _offline(monkeypatch: pytest.MonkeyPatch, *, resolver: bool = True) -> _Net:
    """A recording transport answers every ``httpx.AsyncClient`` made from here on with 200 and ``BODY``; the fetch agent
    waits for no rate-limit slot and consults no egress policy. With ``resolver``, the URL floor keeps its shape check
    alone and ``socket.getaddrinfo`` raises."""
    net = _Net()

    def answer(request: httpx.Request) -> httpx.Response:
        net.sent.append(str(request.url))
        return httpx.Response(200, text=BODY)

    transport = httpx.MockTransport(answer)
    real_client = httpx.AsyncClient

    def client(**kwargs: Any) -> httpx.AsyncClient:
        kwargs.pop("transport", None)
        return real_client(transport=transport, **kwargs)

    async def no_wait(self: HttpFetchAgent, domain: str, state: Any) -> float:
        state.last_request_time = 0
        return 0.0

    monkeypatch.setattr(httpx, "AsyncClient", client)
    monkeypatch.setattr(HttpFetchAgent, "_wait_for_rate_limit", no_wait)
    monkeypatch.setattr(HttpFetchAgent, "_egress_policy", None)
    if resolver:
        def refuse(*args: Any, **kwargs: Any) -> Any:
            net.lookups.append(args)
            raise OSError("ad1346-m3e3b: no name is resolved")

        monkeypatch.setattr("probos.agents.http_fetch.validate_public_url", lambda url, resolve=True: check_url_shape(url))
        monkeypatch.setattr("probos.agents.http_fetch.validate_and_pin_public_url", lambda url: PinnedTarget(check_url_shape(url)))
        monkeypatch.setattr(socket, "getaddrinfo", refuse)
    return net
